# Fresnel

[한국어](README.ko.md) | [中文](README.zh.md)

Fresnel (working name) is a conversational agent runtime. The whole runtime is shipped in layers, and users add or replace plugins and plugin groups at each layer. Helm is a plugin group (L3) that ships by default.

Status: pre-release. The desktop app, CLI and background service are under development; there is no stable release yet.

## Layout

| Path | Contents |
|------|----------|
| `xeon/` | The workspace: engine, host, CLI and desktop app (TypeScript on Bun, Electron shell) |
| `docs/xeon/` | Product plan, per-layer specs and plans, binding engineering rules |
| `packages/agent-docs-init/` | `@helmdocs/init`, the Agent Docs OS installer (a separate tool from the runtime) |

Layers, lowest to highest: F (contracts), X (extension host), L0 (platform), L1 (core), L2 (capabilities), L3 (plugin groups), L4 (apps). A package may import only lower layers.

## Getting started

```bash
cd xeon
mise install      # pinned toolchain
just setup        # bun install --frozen-lockfile
just --list       # every command; run everything through just
just check <pkg>  # lint, typecheck and test one package, e.g. just check packages/core-loop
```

Read `docs/xeon/engineering/onboarding/guide.md` first, then `xeon/AGENTS.md` for the working rules. The documentation index is `docs/xeon/README.md`.
