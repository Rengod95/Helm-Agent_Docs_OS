# 에이전트 런타임 층별 항목 목록 (refs 여섯 보고서 기반)

이 문서는 여섯 조사 보고서(pi, omp, pi durable, opencode, Claude Code, Hermes)의 근거에서 층별 구성 요소를 "항목" 단위로 뽑은 목록이다. 종합본에 있던 항목을 포함하고, 보고서에 근거가 있는 항목을 새로 찾아 추가하였다. 총 119 항목이다.

## 표 열과 약어

- 열: 층 | 항목 이름 | 런타임에서의 역할 | 해결하는 문제 | 보유 런타임과 근거 | 필수도
- 층 약어: F 계약, L0 플랫폼, L1-a 태스크 엔진, L1-b 에이전트 루프, L1-c 모델 게이트웨이, L1-d 도구 실행·권한, L1-e 컨텍스트·컴팩션, L1-f 영속성·복구, L1-g 서브에이전트, L2 능력, X 확장 체계
- 보유 약어: pi(pi 본체), omp(oh-my-pi), dur(pi durable), oc(opencode v2), cc(Claude Code), her(Hermes Agent)
- 근거 표기: `보고서파일명:줄`. 파일은 `scratchpad/research/refs/` 아래에 있고, 줄은 해당 보고서 파일의 줄 번호다. "미보유"는 보고서에 해당 구성 요소가 없다고 적힌 경우다. "근거 없음"은 보고서가 다루지 않은 경우다.
- 필수도 기준: 필수는 빠지면 우리 요구(내구성, 권한, 확장 격리, 멀티 모델, 서브에이전트 수명)가 깨지는 항목이다. 권장은 있으면 크게 낫고 비용이 낮은 항목이다. 선택은 목적이 좁거나 실험 단계인 항목이다.

## 해석 메모

- 필수도 "필수" 중 우리 요구와 직접 맞닿는 것은 F(와이어, 설정 계층, 매니페스트, 버전 정책), L0(저장소 소유, 비밀, 샌드박스, 실행 추상), L1-d(권한, 승인, 훅 실패 정책), L1-f(내구성 수준, 의도와 결과 3단, 재생 정책, 재개), X(구동, 신뢰, 격리, 시간 예산) 층에 몰린다.
