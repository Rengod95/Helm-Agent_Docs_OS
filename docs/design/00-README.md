# Helm 설계 색인

- 작성: 2026-10-19. 소유: 조정자.
- 제품: Helm은 제품 소유자 한 사람이 쓰는 개인용 에이전트 작업 관찰·제어 도구다. 며칠이나 몇 주에 걸친 에이전트 작업을 한 공간에서 보고, 다음 일을 예상하고, 방향을 바꾸고, 이의를 걸 수 있게 한다. 데몬은 개인 WSL2 서버에 상주하고, 데스크톱 앱과 휴대폰(PWA)이 접속한다.
- 이 폴더의 성격: `docs/design/`은 구현 전에 쓰는 설계 문서 묶음이다. 이 파일은 01~26 문서의 색인이다. 규칙은 각 문서 본문이 정하고, 이 파일은 읽을 문서, 결정 요약, 판정과 검증 결과의 위치만 안내한다. 각 문서의 상태(초안, 보완판)는 문서 머리에 있다.
- 기준 결정 범위: 브리프 결정 1~64 (`process/00-design-brief.md` §2).
- 판정 범위: J-01~J-351 (`process/rulings-stage2a.md`).
- 표시 규칙 (브리프 §5.2): `[결정 n]`은 사용자가 정한 결정 번호에만 쓴다. 조정자 기본값은 `[제안: 결정 n 기본값]`, 조정자 판정은 `[판정 n]`(결정 44~46) 또는 `[판정 J-nn]`으로 적는다. `[제안]`은 문서 작성자가 정한 설계 선택이고, `[가정]`은 확인되지 않은 전제다.

## 3. 사용자 결정 1~64 요약

종류는 브리프 §2의 표기를 따른다. 1~25는 08과 09 머리말의 분류에 따라 사용자 결정으로 적었다. 본문에 `[제안]`이 붙은 항목 일부(12, 14, 15, 16)는 해당 절의 표기가 우선한다. 26~32, 34, 36, 37은 조정자 기본값이고, 44~46은 조정자 판정이다. 33과 35는 사용자 확인을 받은 결정이다.
