# R-V4-V7: 1차 V4·V7 치명·높음 지적의 재확인

- 기준: 설계 문서 `docs/design/01`~`26`의 현재 판. 조정자 판정은 `docs/design/process/rulings-stage2a.md`의 J 행이며, §7~§11 행을 우선 확인했다.
- 대상: 1차 `V4-security-ops.md`의 치명 1건(V4-001)과 높음 13건(V4-002~V4-014). 1차 `V7-style-terms.md`의 높음 12건(V7-001~003, V7-010~018)과, 등급은 중간이지만 식별자 부분이 높음인 V7-020. 합계 27건.
- 방법: 검증 파일은 `grep -n '치명\|높음'`으로 지적 행을 찾고 그 행만 읽었다. 지적마다 가리키는 문서·절을 grep으로 찾아 해당 줄 범위만 읽고 판정했다. 줄 번호는 현재 판 기준이다. 설계 문서와 판정 문서는 읽기만 했다.
- 검증 한계: V7-012와 V7-014는 행별 전수 대조가 아니다. 대표 항목 대조와 옛 이름의 부재 확인으로 판정했고, 해당 행의 남은 문제 칸에 그 범위를 적었다.
