# Helm 시스템 이해: 학습 인덱스 (초안)

- 학습 목표: 구현이 끝난 Helm 코드를 사람이 리뷰할 때, 코드가 설계의 구조·동작·불변조건을 지키는지 스스로 판단할 수 있다.
- 계기: 설계 26개 문서(약 5.5만 줄)가 끝났고 곧 에이전트가 구현한다. 구현 결과를 검증할 사람은 제품 소유자 한 명이다.
- 생략한 단계: 기저 지식 진단(사용자 지시). 독자 수준은 아래처럼 추정했다.
  - 이미 아는 것: Helm 이론(v0.3, 결정 1~18), 제품 결정(결정 19~64), 홈랩 환경(WSL2, Tailscale, systemd, SOPS), React CSR, Claude Code·pi 같은 에이전트 도구 사용
  - 들어 봤지만 설계 수준으로는 모를 수 있는 것: 이벤트 소싱과 투영, 멱등 키와 펜싱, 커널 검사 순서, 도구 호출 상태 기계, bwrap 격리, JSON-RPC 재전송
  - 이 추정은 노드를 읽으면서 고칠 수 있다.
