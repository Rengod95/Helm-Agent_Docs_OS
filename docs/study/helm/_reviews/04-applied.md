# 노드 04 리뷰 반영 기록

반영: 기술 문제 중간 13건(A1~A7, B1~B6)과 낮음 중 판단해 반영한 것, 지침 위반, 독자 흐름 문제. 반영 전에 09 §3.2.2·§3.8.4·§3.9.4·§3.10.4·§3.16.4·§3.15.3, 08 §3.18.2·§3.20.1, 17 §3.7(H-2)을 grep으로 확인했다.

## 반영하지 않은 지적

- A2 중 Redux 공식 스타일 가이드의 "action을 이벤트로 모델링" 권장: 환경에서 웹으로 확인하지 못해 본문에서 단정하지 않고 "일어난 일로 모델링하면 이벤트에 가깝고 SET_X로 쓰면 명령에 가깝다"는 조건문으로만 썼다.
- A8: 지표 투영 예외는 반영했으나 "범위 좁히기"는 `p_*` 한정 표현으로만 처리했다.
- A9 중 "짝" 표현: 이름 쌍 설명은 유지하고 1대1이 아님을 덧붙였다.
- B11 심화 블록 이동: 별도 심화 블록은 만들지 않고 한 문장으로 주기와 불일치 시 동작만 적었다.
- B7(해시 계산식)은 반영했으나 B15의 "내부 키 4종 표 이동"은 키 형식을 7.1번 노드로 넘기고 본문에서 뺐다.
- 지침 W28/W30(이벤트 필드 나열을 표로): 필드 서술을 문장 그대로 두었다. 필드 수가 많지만 묶음별 서술이 흐름을 이루고, 분량 조정은 이번 범위 밖으로 판단했다.
- 4번 노드를 4a/4b로 쪼개기, 시퀀스 다이어그램 추가, 글 끝 "대조할 설계 절" 부록: 구조 변경이라 이번 수정에서 하지 않았다. 4.1의 흐름은 번호 단계로 바꾸었다.
- 4.1 끝에 리뷰 포인트 3개 추가(학습 적합성 항목): 체크리스트는 4번 노드에만 있어 4번 체크리스트에 해당 항목(커널 ID 주입, 업캐스터, 마이그레이션)을 반영했고 4.1에는 넣지 않았다.
- 그림 가로 스크롤/다크 테마 등 HTML 변환 관련 지적: Markdown 수정 범위 밖이다. 그림 방향만 TB로 바꿨다.
- 지침 부작용 절(W16, W51, W30, W23, V9-3): 참고만 했다.
- 렌더링은 mmdc가 없어 확인하지 못했다.
