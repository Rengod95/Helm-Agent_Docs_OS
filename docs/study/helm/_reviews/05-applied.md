# 05 리뷰 반영 기록

## 반영하지 않은 지적
- T12 (승격 조건의 다이얼 의존): 설계 문서 내부 불일치라 설계는 고치지 않고, 글에 "기본 설정에서"만 붙였다. 설계 이슈로 별도 확인 필요.
- T13 중 `policy.structure_cap_exceeded` 외 "충돌 두 쓰임" 구분: 갈래 표에 `conflict.invalid_transition` 예시만 보태고 별도 설명 절은 두지 않았다.
- W2 (속성 테스트, TypeBox, P-1~P-12 풀이), W22 중 갈래 표 앞 문장 반복: 범위와 분량 때문에 보류했다.
- W43 중 "허락/승인/확인", "제출/명령/봉투" 통일: 04·04a 표기 확인이 필요해 보류했다.
- 독자 흐름 4(01의 "능력부터 검사" 표현과 순서 차이), 6(점검 항목별 대응 시험 번호), 7(승격·예산 절 축소), 8(약어 삭제는 반영, 나머지 없음): 다른 노드 글 또는 구조 개편이 필요해 보류했다.
- 표상 (b)(c) 그림에 error 종료와 결과 종류 추가: 그림이 복잡해져 본문 문장으로 대체했다.
- T3의 "뒤 단계는 평가하지 않는다"는 설계 문서에 명시가 없어 추론으로 반영했다(설계 확인 권장).
- Mermaid parse는 이 환경에 mermaid가 없어 실행하지 못했다. 라벨 문자열만 바꿨고 구문은 그대로다.
