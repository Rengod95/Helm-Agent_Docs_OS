- 인증 실패 지연 상한과 `1011` (T4): 18 §3.14와 19 §3.4.5가 다름. 일치하는 두 점은 단정하고 다른 값은 "아직 정리 중"으로 썼다. design-gaps.md에 항목 추가.

## 반영하지 않은 지적
- 위협 표에 T-H4(다른 uid·root) 행 추가: 행은 넣지 않고 경계 B 문단에 "범위 밖"으로 한 문장만 썼다.
- 용어 "주체", "hop", "상수 시간 비교", "Funnel"의 별도 정의: 독자가 아는 범위로 보아 "노드 묶기"만 정의했다.
- 비밀·공급망 절 분리: 리뷰가 지적한 흐름 끊김은 절을 나누지 않고 문단 순서와 점검 항목 추가로 대응했다.
- T8의 발송 `deny`/`ask` 세부(합의 유무): 8번 노드 참조로 줄이고 "합의로도 바뀌지 않는 항목" 구분만 넣었다.
- 지침 부작용 절(W16, W17, W23, W31, W51 지침 개정 제안): 학습 글 수정 범위 밖이라 참고만 했다.
- Mermaid 렌더링: 파서가 없어 문법 검사는 하지 못했다(`subgraph` 중첩, 따옴표 라벨로 작성).
- 티켓 경로(18과 19 불일치): 글이 경로를 쓰지 않아 해당 없음.
