# 노드 08 리뷰 반영 기록

1차 자료(13 §3.3.7, §3.4.3, §3.5.3, §3.6.1, §3.10, 18 §3.11.5~6, R-6, R-14, research-ohmypi)를 grep으로 확인한 뒤 반영했다. 높음·중간(T1~T9)은 모두 반영했다. 렌더러가 없어 Mermaid는 문법을 눈으로 확인했다(flowchart LR, 노드 라벨은 따옴표, 줄바꿈은 br).

## 반영하지 않았거나 일부만 반영한 것
- T15 (샌드박스 불가 시 남는 도구): 글은 "읽기와 Helm 도구만"을 유지했다. 13 안의 불일치는 설계 문서 쪽 이슈라 글에서 고치지 않는다.
- 문서 간 차이 3번(systemctl 범위): 기준선 나열을 13번 노드로 넘기면서 `systemctl` 언급을 글에서 뺐다. 한쪽 단정을 피했다.
- 문서 간 차이 4·5·6번(web_fetch 크기, 변환 미디어 타입, 변경 감지 방식): 모순이 아니거나 글이 이미 13을 따르므로 그대로 두었다.
- S1b 상태 표시(13은 critical, 18은 degraded): 서로 다르므로 글에는 "격리 수준 낮음 배지"와 `pre_read_exposed`만 적고 상태 등급은 쓰지 않았다.
- 3.2 범위(Helm 제안 도구 생성 규칙, MCP 도구 추가, MVP 후반 기능 심화 이동): 분량과 노드 범위 조정 사항이라 이번에는 하지 않았다. 해시라인과 브라우저는 개수 단정만 제거했다.
- 3.1의 일부(원자적 쓰기 소제목은 반영, 방어 항목에 위협 이름 붙이기는 DNS 리바인딩과 리디렉션 우회 두 곳만 반영, 마운트 표는 Mermaid 그림 안에 합침).
- W2 용어: tmpfs, realpath, 마운트 네임스페이스, CONNECT 프록시, CDP, Syncthing은 풀었다. EROFS, playwright-core, `fsync`는 풀지 않았다.
- W16 결정 번호: "결정 55"만 남기고 나머지(2, 61, 63)는 뺐다.
- 5 지침 부작용 항목: 이 글 수정과 무관한 지침 개선 제안이라 반영 대상이 아니다.
- 점검 목록의 22번 시험 번호 연결(3.3 a): 시험 번호를 확인하지 않아 넣지 않았다.
