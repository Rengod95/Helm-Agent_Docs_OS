- `~/projects/.stignore-dev`에 `.git`이 있다. 작업 트리는 Mac과 동기화되고 `.git`은 동기화되지 않는다.
- 홈랩 `context/storage.md:124,130`: restic 대상은 `~/projects`(`.git` 포함), `~/data`, `~/vault`, `/srv/volumes/<svc>`(compose 라벨 `backup=true`만). `/srv/volumes/helm`은 지금 대상이 아니다(17:111 [실험 20]과 같다). D: 백업은 같은 NVMe다(storage.md:139).
- 자격 증명 파일의 존재 여부는 확인하지 않았다(자격 탐색 금지). V4-002는 일반적인 개발 환경 파일 이름을 예로 든다.

1. 브리프 결정 2, 14, 15, 26, 38, 45~49와 §2.5를 기준으로 자산·공격자·경로를 다시 세웠다.

4. 심각도 정의: 치명 = 핵심 요구 위반·데이터 손실·보안 사고·구현 불가, 높음 = 모순·누락으로 구현자가 추측해야 하고 틀리면 재작업이 큼, 중간 = 기본값으로 진행 가능, 낮음 = 표기·참조.
