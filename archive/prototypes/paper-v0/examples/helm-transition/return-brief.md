## 3. What it means

- Helm은 더 이상 “에이전트가 읽을 문서 구조”만으로 정의될 수 없다.
- 현재 가장 큰 위험은 검증되지 않은 풍부한 ontology를 곧바로 안정 schema로 구현하여 관료적인 제품을 만드는 것이다.
- 반대 위험은 v0 문서 스캐폴드에 머물러 실제 인간–에이전트 상호작용을 만들지 못하는 것이다.
- 가장 정보 가치가 높은 다음 행동은 네 primitive를 실제 작업에서 사람이 수동 운영해 보는 것이다.
- 아직 설명되지 않은 부분은 사용자가 어떤 개입을 즐겁고 가치 있게 느끼며, 어느 지점부터 감독 피로로 느끼는가이다.
- Git-only collector는 56개 file change를 포착했지만 목적·결정·믿음·다음 행동을 복원하지 못했다.
- human context로 의미 영역을 채울 수 있었지만 56개 파일 행을 그대로 노출해 인지적 압축에는 실패했다.
- 네 artifact를 각각 장문의 form으로 고정하기보다 대화에서 소수 semantic Event를 포착하고 역할별 projection으로 생성하는 방향이 현재 관찰과 더 잘 맞는다.
