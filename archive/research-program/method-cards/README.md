## Evidence status 해석

각 카드의 `Evidence status`는 원래 방법론의 근거와 Helm 전이 근거를 구분한다.

- 원래 분야에서 검증되거나 제도화된 방법도 Helm에서 효과가 있다는 직접 증거는 아직 없을 수 있다.
- 여러 분야에서 유사 메커니즘이 반복되는 것은 전이 후보를 강화하지만 제품 인과 증거를 대신하지 않는다.
- 실제 Helm pilot 결과가 기존 전이를 반박하면 카드 상태를 `rejected` 또는 `superseded`로 변경한다.

## 다음 연구 깊이

20개 카드는 첫 운영 이론을 구성하기 위한 우선 원전 분석이다. 남은 35개 지도 항목은 실제 pilot에서 새로운 failure mechanism 또는 설계 선택이 발생할 때 개별 Card로 승격한다. 문헌 수를 늘리는 것 자체를 연구 진척으로 간주하지 않는다.
