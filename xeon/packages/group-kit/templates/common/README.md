# __TITLE__

- 그룹 이름: `__ID__`
- 버전: `__VERSION__`
- 만든 방법: `xeon/packages/group-kit/templates/`의 그룹 템플릿

## 의도

이 그룹이 하는 일을 한 문장으로 적는다.

## 판정 기준에 답하기

새 그룹은 기존 그룹과 무엇이 다른지 답해야 한다. 답이 없으면 기존 그룹의 설정으로 해결한다.

- 어떤 사용자 목적을 위해 만들었는가?
- 기존 그룹이 같은 일을 할 수 없는 이유는 무엇인가?

## 설정 키

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `ext.__ID__.*` | 템플릿 `src/settings.ts` 참고 | 키를 더하면 여기 적는다 |

켜기와 끄기는 `ext.__ID__.enabled`(X가 예약한 키)로 한다. 이 키는 설정 파일에 두지 않는다.
