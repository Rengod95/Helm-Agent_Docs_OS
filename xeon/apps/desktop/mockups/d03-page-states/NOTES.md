# d03 기존 페이지 빠진 상태 (P-04, P-07, P-08, P-09, P-10, P-11, P-12, P-14, P-15, O-06)

## 구성
- 한 폴더, `?page=pNN&state=<id>`. 페이지마다 원래 폴더 코드를 `pNN/`로 복사했고(가져오기 경로만 한 단계 깊게), 원래 `main.tsx`는 `entry.tsx`(STATES + Root 내보내기)로 바꿨습니다. 원래 폴더는 고치지 않았습니다. 새 상태 id는 `D-`로 시작해 원래 상태와 섞이지 않습니다.
- 페이지 하나에 폴더 하나를 두면 빌드가 아홉 번 돌고 공용 고침이 아홉 곳에 흩어져서 한 폴더로 묶었습니다.

## 페이지별 결정
- P-04: spec §6.8은 "권한 필요: 해당 없음"이지만 coverage가 칸을 요구해, 제출할 권한이 없는 두 경우를 그렸습니다: 관찰 중(다른 클라이언트가 쓰기 소유, "쓰기 다시 시도"), 다른 곳에서 이미 답함(approval.resolved, 읽기 전용). 결정 버튼과 제출이 잠깁니다.
- P-07: 오프라인은 목록 유지 + 동작 잠금 + 마지막으로 읽은 시각. 행 메뉴에 "실행 기록", "고치기…", "끄기", "지우기…"를 더했고 꺼진 예약 행에는 "다시 켜기" 버튼이 바로 보입니다. 실행 기록은 오른쪽 Sheet(결과·시각·걸린 시간·이유·그 실행의 대화). O-06 예약 변형은 d01 부품을 씁니다.
- P-08: 읽는 중은 목록·상세 Skeleton. 서비스 멈추기 확인은 영향(진행 중 턴, 대기 예약, 다른 클라이언트)을 목록으로. 다시 시작 중은 상태 점·칸이 warning. 유휴 종료는 상세 위 neutral Alert와 "계속 켜 두기". 상태 표시줄 대상 칸 Popover에 요약 + "대상 바꾸기"·"연결 화면". 웹은 "대상 바꾸기" 없이 "다른 서비스는 새 탭으로".
- P-09: 개요 탭 맨 아래 "데이터" 묶음(크기·위치, "모든 대화 내보내기…", danger 글자 "데이터 지우기…"). O-06 데이터 변형은 지우는 것·남는 것 목록, 시크릿 값·사용자 확장 고르기, 확인 글 입력, 진행 중이면 못 지움.
- P-10: 읽는 중 Skeleton, 오프라인(설정 틀 띠 + 동작 잠금), 사용 기록(W-13: 시각, 대화와 도구, 쓰인 모습 ENV·헤더, 출처, 거절). 웹은 "OS 재인증이 없어 값을 볼 수 없어요". 복사본에서 CLI 안내(`fresnel secret reveal`)를 뺐습니다(2026-11-01 결정).
- P-11: 빈 계정 풀은 provider 묶음 안 EmptyState + "계정 더하기", 회전은 계정이 둘 이상이어야 켤 수 있어 잠금. 읽는 중 Skeleton.
- P-12: 오프라인은 설정 틀 띠 + 순서 바꾸기 잠금.
- P-14: 오프라인은 마지막 값 흐리게 + neutral Alert. 오류는 작업 목록 바로 위 danger Alert(DP-28).
- P-15: 크래프트 "엔진" 자리(왼쪽 크래프트 내비 "엔진" 선택). 맨 위 "엔진 상태"(상태·최근 다시 시작 횟수, 대상 + "연결 화면 열기" 한 줄, 안전 모드, 앱 업데이트 줄). 안전 모드 문구는 d02 `SAFE_OFF`(X 훅 포함, 결정 12). 팔레트 힌트의 CLI 명령도 뺐습니다.
