# e02 바로 가기 키와 키 바꾸기 (O-09, 계획에 없음 9·11)

## 레이아웃 결정
- 옛 `o09-shortcuts`의 Dialog(lg, 찾기 + 두 열 + `Kbd`)를 그대로 두고 키를 그리는 유일한 화면이라는 예외(DP-06)를 지킵니다. 다른 화면에는 키를 그리지 않습니다.
- 새 묶음 "영역": ⌘E(대화 ↔ 크래프트), ⌥⌘1(대화 영역), ⌥⌘2(크래프트 영역), F6(다음 구역, e01 제안).
- 키 바꾸기(계획에 없음 11): 행에 마우스를 올리거나 초점이 가면 연필 버튼 하나. 누르면 키 자리가 "새 키를 누르세요 · Esc 취소" 칸으로 바뀌고 다음 조합을 받습니다(단독 수정 키는 무시). 겹치면 그 행 바로 아래 warning Alert 하나(바꿔 쓰기 · 취소). 바꿔 쓰면 다른 동작은 "키 없음"(warning 글자)이 됩니다. 바뀐 행은 "바뀜"과 되돌리기 아이콘, 바닥에 "모두 기본값으로"와 "바뀐 키 n개 · 이 기기에만".
- 저장은 `l4.desktop.appearance.keybindings`(동작 id → 키). 기기마다 따로입니다(웹·데스크톱 키가 다르고, 키보드도 다름).
- 입력창·승인 카드 글자 키(Enter, Y, N)는 바꾸지 않습니다(연필 없음).
- 웹 표(계획에 없음 9): 머리 오른쪽 `SegmentedControl`(데스크톱·웹). 웹에서는 브라우저가 막을 수 없게 가져가는 키(⌘N, ⌘W, ⌘T, ⌘1–5)를 줄 그은 연한 `Kbd`로 두고 옆에 대체 키(⌥⇧N, ⌥⇧1–5)를 보입니다. 웹에서 그 키를 고르면 "브라우저가 가져가 웹에서는 쓸 수 없어요" Alert와 "다른 키 누르기"만(바꿔 쓰기 없음). 실제 웹 클라이언트에서는 이 표가 기본이고 Segmented는 없습니다.

## caustic 부품
`Dialog`(lg, alert), `Input`, `Kbd`, `SegmentedControl`, `Alert`(actions), `IconButton`, `Tooltip`, `toast`.

## 직접 만든 것과 빈틈
- 키 기록 칸은 caustic에 "단축키 입력(KeyRecorder)" 부품이 없어 토큰으로 만들었습니다(accent 안쪽 선 한 줄, role=status).
- 키 표기는 macOS(⌘⇧⌥↩)·Linux(Ctrl+Shift) 두 가지(`linux` 상태).

## 웹·좁은 폭
- 700에서는 두 열이 한 열로 접힙니다. 390(모바일)에는 키 도움말을 두지 않습니다(물리 키보드가 붙은 태블릿만, 같은 표).
