# a01-trial-chat 시나리오

테스트 대화 머리(N-02), 멈춤 띠(N-03), 대화 목록 테스트 표지(N-04)를 눌러 봅니다. 상태와 시나리오는 `flow.ts`의 상태 기계 하나입니다: `?state=<id>`는 대본의 앞 n개 동작을 바로 적용한 모습이고, `?scenario=<id>&step=<n>`도 같습니다. `&hold=1`이면 그 순간에서 멈춥니다(스크린숏용). 없으면 거기서부터 이어서 돕니다. `?dev=1`이면 시나리오 막대가 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `trial-pause-resume` | ① 입력창의 준비된 문장 보내기 → ② 띠 "멈춤" → ③ (기다림) → ④ "한 단계씩" → ⑤ "이어서" → ⑥ 끝 띠의 "끝난 테스트 지우기" | ① 실행 중 띠, 단계 진행 ② "멈추는 중 · 이번 단계가 끝나면 멈춰요"(스피너, 버튼 잠김) ③ 다음 단계 사이에 도착: "단계 사이에서 멈춤 · 주도 helm 유지", 런타임 줄·런타임 탭·목록 표지가 "멈춤" ④ 한 단계만 돌고 다시 멈춤 ⑤ 이어서 끝까지, "helm이 주도를 놓았어요 · 테스트 끝" ⑥ 이 테스트와 끝난 다른 테스트가 목록에서 빠지고 빈 상태 | 결정 캔버스 9, C-9, W-48, X-19, spec §6.30 |
| `trial-queue` | 멈춘 동안 입력창에 쓰고 보내기 → "이어서" | 보낸 글은 트랜스크립트에 들어가지 않고 입력창 위 "대기 중인 입력 1개 · 이어서 하면 보내요 · “…”" → 이어서 하면 "멈춘 동안 보낸 입력" 표지로 들어감 | C-9(멈춤 중 입력은 큐에만) |
| `trial-autodisable` | 보내고 기다림 → "다시 켜고 이어서" | 3단계 뒤 helm이 자동 꺼짐: danger 띠 "helm이 자동 꺼짐이라 테스트를 멈췄어요 · 연속 실패 5", 런타임 탭 실패 구역, 상태 표시줄 "확장 실패 1" → 다시 켜면 "helm을 다시 켰어요 · 이 테스트 대화에만" 뒤 이어서 | authoring §5(테스트 중 자동 꺼짐), spec §6.30 |

스크린숏 순간: `sc-pause-resume-4`(멈추는 중), `-6`(한 단계씩), `-12`(끝), `sc-queue-7`(큐가 들어감), `sc-autodisable-6`(다시 켬).

## ?state= 목록

| id | 모습 |
|---|---|
| `paused`(기본) | 단계 사이에서 멈춤, 주도 helm 유지, "한 단계씩"·"이어서" |
| `draft` | 새 테스트 대화: 머리 Badge·프로필·대상, "이 대화에서만 켰어요" 행 |
| `running` | 실행 중 띠와 "멈춤" |
| `pausing` | 멈추는 중(다음 단계 사이 기다림) |
| `stepping` | 한 단계만 진행 중 |
| `queued` | 멈춤 중 입력 큐 |
| `finished` | 끝: "크래프트에서 결과", "끝난 테스트 지우기" |
| `cleared` | 끝난 테스트 지움(빈 상태 "결과는 크래프트 테스트 실행에 읽기 전용으로 남아요") |
| `disabled` | 대상 자동 꺼짐으로 멈춤 |
| `narrow` | 390px: 머리는 Badge만, 띠는 상태 글과 동작만 |
