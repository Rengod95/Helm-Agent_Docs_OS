# c01-trials 메모

P-19 시험 실행 다시 그리기(시험 대화가 기본 행), O-12 새 시험, N-30 개발 모드입니다. O-12와 개발 모드 대화 상자는 이 화면이 여는 것이라 같은 폴더의 상태로 두었습니다.

## 레이아웃 결정

- 한 화면 두 구역: 위 "시험 대화"(배포 앱에서 만들고 돌리는 것), 아래 "다시 돌려 검사 · 성능 측정 · 보호 코드 변경 검사"(개발 모드 전용). 배포 앱이면 아래 구역 머리에 "지난 결과 · 읽기 전용"과 "개발 모드에서만" 배지 하나만 둡니다. 행마다 자물쇠를 반복하지 않습니다.
- 지난 replay 결과는 배포 앱에서도 판정·절단 수·첫 차이를 읽기 전용으로 보입니다. 절단 띠·효과 수·이벤트 비교·JSON 복사(ReplayDriveReport 전체, 결정 9)는 개발 모드에서만 보입니다. 리드 지시("보고는 개발 모드에서만")와 결정 4("지난 결과 읽기 전용")를 함께 맞춘 절충입니다.
- 잠긴 "다시 실행"은 회색 단추 그대로 눌리고, 누르면 이유 툴팁이 열립니다(비활성 단추는 툴팁을 못 띄워서). 옆에 "개발 모드 켜기…" 하나.
- 고른 행 상세는 표 아래 같은 흐름입니다(나눔 창 `[gap:C-14]`). 시험 대화 상세 = 입력창 위 띠와 같은 면의 제어 띠(멈춤 / 한 단계씩 · 이어서) + 목록(대상, 프로필, 시작) + 턴 다시 보기 막대 + 단계 사이 기록. 자동 꺼짐으로 멈춘 시험은 단계 사이 기록 대신 실패 기록을 보입니다.
- 개발 모드 배지 자리: 상태 표시줄 왼쪽 묶음 끝 "개발 모드" 칸(켜졌을 때만, DP-27). Popover에 저장소 경로와 "개발 모드 끄기". 웹은 원격 호스트 이름과 "그 컴퓨터의 설정에서 바꿔요".
- O-12 바닥은 비용 문장 → 누르면 확인 문장으로 바뀌는 두 단계입니다(대화 상자를 겹쳐 띄우지 않음).
