# c01-trials 시나리오

P-19 테스트 실행 다시 그리기, O-12 새 테스트, N-30 개발 모드를 눌러 봅니다. 상태와 시나리오는 `flow.ts`의 상태 기계 하나입니다. `?state=<id>`는 대본의 앞 n개 동작을 바로 적용한 모습이고, `?scenario=<id>&step=<n>`도 같습니다. `&hold=1`이면 그 순간에서 멈춥니다(스크린숏용). 없으면 거기서부터 이어서 돕니다. `?dev=1`이면 왼쪽 아래에 시나리오 막대와 "다음에 누를 것"이 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `trial-new` | ① 머리 "새 테스트" → ② "시작" → ③ "토큰 쓰고 시작" → (기다림) | ① 오른쪽 시트: 종류는 테스트 대화가 기본, 다시 돌려 검사·성능 측정·보호 코드 변경 검사는 "개발 모드에서만" 잠금, 프로필 미리 보기("이 대화에 적용하면") ② 바닥이 확인 문장 "모델 토큰을 써서 테스트 대화를 시작할까요? 예상 40k"로 바뀜 ③ "프로필 적용 중 · 이 대화에만" → "테스트 대화 만드는 중" → 시트가 닫히고 새 행이 맨 위에 실행 중으로 생김, 내비 배지 "1*", 상세 "멈춤" 띠 | spec §6.26, §6.31 O-12, 결정 4, W-34·W-44 |

## ?state= 목록

| id | 모습 |
|---|---|
| `list`(기본) | 배포 앱. 위 구역 테스트 대화 3, 아래 구역 지난 결과(읽기 전용, "개발 모드에서만"). 멈춘 테스트 대화 상세: 제어 띠, 턴 다시 보기 막대, 단계 사이 기록 |
| `running` | 새 테스트 대화 실행 중(단계 사이 기록이 아직 없음) |
| `stopped` | 테스트 중 대상 자동 꺼짐: danger 띠 "리뷰가 자동 꺼짐이라 테스트를 멈췄어요" + 실패 기록(`file:line`) |
| `past-locked` | 지난 replay 결과 요약(판정, 절단, 첫 차이) + 읽기 전용 표지 |
| `lock-tooltip` | 잠긴 "다시 실행"의 이유 툴팁 |
| `devmode-dialog` · `devmode-checking` · `devmode-norepo` | 개발 모드 켜기 대화 상자, 확인 중, 실패 |
| `dev` | 개발 모드: ReplayDriveReport 전체 + JSON 복사 |
| `dev-rerun` | 다시 돌리는 중(절단 24/41) |
| `new` · `new-confirm` · `new-starting` · `new-preview-fail` | O-12 시트, 확인 문장, 프로필 적용 중, 미리 보기 실패 |
| `trace-off` | 계측이 꺼져 턴 다시 보기 잠김 + "설정에서 켜기"(c04로) |
| `turn-evicted` | 끝난 테스트 "렌즈 3개와 비교"의 턴 기록이 버퍼 밖으로 밀려남: 막대 자리에 "이 턴의 기록은 남아 있지 않아요"(동작 없음). 다른 행을 고르면 막대가 돌아옴(N-39, spec §6.22.5) |
| `empty` | "아직 돌린 테스트가 없어요 [새 테스트]" |
| `web` | 웹: 원격 컴퓨터 build-box의 개발 모드를 따름(상태 칸 "개발 모드", 켜기 단추 없음) |
| `narrow` | 390px: 표가 두 줄 목록, 상세는 아래로 쌓임 |
