# e05 웹·좁은 폭·원격 작업대 (계획에 없음 7·8, N-59, N-60)

## 웹 첫 화면과 연결(계획에 없음 7)
- 목업 전용 브라우저 틀(탭 한 줄 + 주소 줄) 안에 그립니다. 연결 전에는 데스크톱 셸이 없습니다: 가운데 한 열(22rem) "Xeon · 다른 컴퓨터의 서비스에 붙어요", 서비스 주소(주소 줄에서 채움, mono, 읽기 전용), 접속 토큰(password), "이 브라우저에서 30일 기억하기", 연결. 토큰 만드는 곳은 "서비스 컴퓨터의 <제품 이름> 앱 › 연결 › 웹 접속"(CLI 없음). 제품 이름은 정하는 중이라 화면의 모든 제품 이름은 `T.productName` 하나로 씁니다(머리, 도움말, 탭 제목, 원격 권한 안내).
- 같은 연결 상태 기계: idle → connecting → live | authFailed | unreachable, live → reconnecting → live | offline. 토큰 틀림은 입력칸 아래 FieldError(남은 시도와 10분 잠금), 닿지 못함은 폼 위 danger Alert + 다시 시도.
- 연결된 뒤에는 같은 셸이 브라우저 안에서 돕니다. 상태 표시줄: "웹 · build-box" 대상 칸, 엔진 칸 없음(서비스 쪽 일), 대상 바꾸기 없음. 끊기면 연결 칸 "다시 연결 중 n" → "끊김"(danger)과 입력창 위 warning 띠 "쓰던 글은 남고…" + 지금 다시 연결, 목록 흐림, 입력 잠금. 다시 붙으면 토스트 "놓친 항목 2개를 받았어요"와 트랜스크립트에 그 항목.

## 좁은 폭(720 미만, 계획에 없음 8, N-59)
- 데스크톱 창은 최소 720이라 이 폭은 웹과 모바일 앱에서만 생깁니다. 그래서 데스크톱 셸의 compact 단계를 늘리지 않고 좁은 폭 전용 배치를 둡니다.
- 전체 화면 셋: 대화, 받은 요청, 승인. 작업대는 읽기 전용 확장 목록 하나("작은 화면에서는 읽기만 해요", 켜기 열 없음).
- 머리 한 줄(48px): 왼쪽 시트 열기 · 제목(+ 런타임 줄 요약) · 런타임(아래 시트) · 받은 요청(숫자 배지). 누르는 곳 40px 이상. 상태 표시줄은 없습니다(연결이 끊기면 머리 아래 띠, 제안).
- 왼쪽 패널 → 왼쪽 시트(주 내비 셋 + 대화 목록 + 설정). caustic `Sheet`에 side="left"가 없어 토큰으로 만든 서랍입니다(빈틈).
- 오른쪽 well → 아래 시트(`Sheet side="bottom"`, 런타임 탭 내용 그대로).
- 승인은 목록에서 한 번 눌러 전체 화면 상세로(명령 전문·위험도·비밀 핸들·cwd), 아래 큰 버튼 거부·허용(44px)과 "이 대화에서 항상"(ghost). 다른 곳(데스크톱)이 먼저 답하면 상세 위 neutral Alert "데스크톱에서 이미 허용했어요(14:06)"와 버튼 잠금.
- 알림: 탭이 앞에 있으면 앱 안 알림 띠(위에서 내려옴, "보기"), 뒤에 있으면 브라우저 알림(권한 필요)이나 앱의 OS 알림. 받은 요청 아이콘 배지 숫자가 늘어납니다.
- 설정 700: 탭 열이 `Select` 하나로(DP-37, 공용 설정 틀이 이미 함, `m-settings`).

## 원격 대상 작업대(N-60)
- 상태 표시줄 대상 칸 "원격 대상 · build-box". 화면 머리 meta "build-box", 둘째 줄 "바꾸기 권한 없음".
- 확장 켜기·끄기는 원격 서비스의 권한(`ext.manage`)이 필요합니다. 읽기 토큰이면 표 위 neutral inline 문장 하나로 미리 말하고, 그래도 누르면 build-box에 묻고 거부되면 danger Alert(DP-28) "켜기를 build-box가 거부했어요 · 권한 없음(ext.manage)…"과 "권한 안내 복사". 스위치는 그대로.
- 프레임 화면 파일은 원격에 있습니다(`build-box:~/.xeon/extensions/acme-notes/view/index.html`). 서비스가 격리된 주소로 보내 주고 이 컴퓨터에 저장하지 않는다는 한 문장(P-17 화면 탭).
- "폴더 열기"·"파일 열기"는 이 컴퓨터의 OS 동작이라 원격에서는 "경로 복사"로 바꾸고, 원래 항목은 이유를 단 채 잠급니다(행 메뉴, 화면 탭).
