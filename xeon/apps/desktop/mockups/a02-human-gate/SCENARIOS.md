# a02-human-gate 시나리오

사람 확인 관문(N-05), 자식 에이전트 승인 출처(N-06), 만료 뒤 모습(N-07), 주도 충돌 "이 그룹 먼저"(계획에 없음 3), Helm well 정리(P-05)를 눌러 봅니다. 상태와 시나리오는 `flow.ts`의 상태 기계 하나입니다(`?state=` = 대본 앞 n개 동작, `?scenario=<id>&step=<n>`, `&hold=1`이면 그 순간에서 멈춤). `?dev=1`이면 시나리오 막대와 다음에 누를 것이 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `ask-lease-release` | (1.8초 기다림) → 질문 카드에서 고르고 "답하기" | helm이 단계 중간에 묻습니다: 런타임 행 "helm이 사람 확인을 기다려요 · 주도 반납", 질문 카드(출처 `grp:helm`, "14:21에 추천안으로 자동 답"), 머리 런타임 줄 "helm 사람 확인 기다림 · 주도 반납", 상태 표시줄 "helm 확인 기다림", 런타임 탭 보유 없음 + "사람 확인" 배지 → 답하면 카드가 기록 줄로 접히고 "답했어요 · helm이 주도를 다시 받음", 이어서 적용 | spec §6.30, X-17, 결정 캔버스 8, flow §7.2 |
| `ask-expire` | 아무것도 누르지 않음(6초) | 실패 갈래: 만료 → 카드가 "답이 없어 자동으로 답했어요 · 만료" 기록, "15분 동안 답이 없어 기본 답으로 자동 답했어요"(core), "helm이 기본 답으로 이어서 진행해요 · 주도 다시 받음" | §6.7 expiresAt, ADR-0021 §3.6.6 |
| `ask-other-thread` | "테스트 정리"를 보는 중 (2.5초) → 토스트나 OS 알림의 "열기" → 답하기 | 다른 대화에 있을 때: 앱 안 토스트 "질문 필요: helm, 캐시 무효화 조사"(열기), OS 알림 미리보기(앱 밖), 받은 요청 배지 +1, 목록 행 "승인 2" → 열면 그 대화와 카드 | flow §7.2, L4.desktop 알림 `question_waiting` |
| `child-approval` | (1.8초) → "허용" | 렌즈(자식)가 낸 도구 승인: 런타임 행 "렌즈 실패 사례가 도구 승인을 기다려요 · 다른 렌즈는 계속", 카드 부제 "렌즈 실패 사례 · grp:helm · 14:16에 자동 거부" → 허용하면 "렌즈 실패 사례가 이어서 진행해요" | 결정 7, DP-33, U-7 |
| `approval-expired` | 아무것도 누르지 않음(6초) | 실패 갈래: 카드가 "답이 없어 자동 거부했어요 · 만료", "10분 동안 답이 없어 자동 거부했어요"(core), "렌즈 실패 사례가 거부를 받고 읽기만으로 이어가요 · helm 계속 진행" | §6.7, N-07 |
| `drive-conflict-first` | 런타임 탭 차례 행 review의 "이 그룹 먼저" | 버튼이 "다음에 먼저"(잠김)로, 행 "review가 다음 단계 사이에서 먼저 주도를 받아요 · 이 대화에만" → 3초 뒤 단계 사이에서 교대: "helm이 주도를 놓았어요 · review가 받았어요", 보유 review, helm이 차례 기다림 | 계획에 없음 3(고르는 창 없음, `activeDriveGroup`) |
| `drive-conflict-withdrawn` | "이 그룹 먼저" | 실패 갈래: review가 기다림을 거둠 → 경고 행 "review가 더는 기다리지 않아요 · 차례를 거뒀어요 · helm이 계속 진행"(출처 `grp:review`) | 실패 갈래 |

스크린숏 순간: `sc-<시나리오>-<n>.png`(예: `sc-ask-lease-release-2` 반납, `-4` 다시 받음).

## ?state= 목록

| id | 모습 |
|---|---|
| `asking`(기본) | 사람 확인 기다림, 주도 반납 |
| `answered` | 답함 → 주도 다시 받음, 적용 진행 |
| `ask-expired` | 만료 → 자동 답, 진행 재개 |
| `other-thread` | 다른 대화(테스트 정리)에서: 토스트 + OS 알림 미리보기 |
| `other-inbox` | 같은 순간, 받은 요청 탭의 질문 요약("답하기") |
| `other-jumped` | 알림에서 그 대화로 |
| `child-approval` | 렌즈 승인 카드(출처 "렌즈 실패 사례 · grp:helm") |
| `child-allowed` | 허용 뒤 |
| `approval-expired` | 만료 → 자동 거부 |
| `conflict` | 런타임 탭: review 1번째(이 그룹 먼저), work 거부(진행 한도) |
| `conflict-first` | "이 그룹 먼저" 누름 |
| `conflict-switched` | 단계 사이에서 교대 |
| `conflict-withdrawn` | 실패: 기다리던 그룹이 거둠 |
| `helm-well` | Helm well: 주제·단계·렌즈·발견만, 주도 구역 없음(P-05) |
