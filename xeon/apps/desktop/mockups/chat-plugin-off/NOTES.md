# A5 이 대화에서 플러그인 끄기 — 메모

사용자 결정 A5(2026-11-04): 대화 영역 오른쪽 "플러그인" 탭에 "이 대화에서 끄기" 스위치를 둔다. 시안을 먼저 보고 구현한다. 이 폴더는 구현이 아닌 시안이다.

## 실행

- 개발 서버: `MOCKUP=chat-plugin-off bun run mockup` (`apps/desktop`에서, 포트 5180)
- 정적 빌드: `MOCKUP=chat-plugin-off bun run mockup:build` (저장소 밖 `<tmpdir>/fresnel-mockups/chat-plugin-off`, `MOCKUP_OUT`으로 바꿈)
- `?state=S1..S6`, `?theme=dark`, `?dev=1`

## 상태

S1 모두 켜짐 · S2 하나를 이 대화에서 끔 · S3 전역에서 꺼진 플러그인(스위치 잠김) · S4 턴 진행 중이라 "이번 단계가 끝나면 꺼져요" · S5 저장 실패(되돌림 + 다시 시도) · S6 열린 대화 없음.

## 결정한 것(시안 기본값)

- 스위치 켬 = 이 대화에서 쓴다. 끄면 행에 "이 대화에서 꺼짐" 배지, 탭 막대에는 꺼진 수 배지.
- 적용은 다음 단계 경계다. 턴이 없으면 곧 적용(토스트 "다음 턴부터 적용돼요").
- 전역에서 꺼진 플러그인은 이 대화에서 켤 수 없다(잠김 + 툴팁).
- 엔진: `settings.set` 범위 launch + `threadId`(구현할 때).

## 빈틈

- 시안은 대화 영역 셸(`_shell`)을 그대로 쓰고 플러그인 탭 아이콘은 임시(`MessageSquare`)다.
- 그룹 안 개별 플러그인을 끄는 단위(그룹 하나가 스위치 하나, 15-1)는 정하지 않았다. 행은 그룹 또는 플러그인 하나다.
- 실제 브라우저로 화면을 보지는 못했다(빌드만 확인).
