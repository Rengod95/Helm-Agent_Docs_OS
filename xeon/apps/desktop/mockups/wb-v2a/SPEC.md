# 런타임 지도 · 구성기 v2 — 방향 A "구조가 보이는 지도" (wb-v2a)

작업대 "개요"(P-16)와 "구성"(P-21, 만들기 P-22를 합침)을 한 시각 언어로 다시 그린 제안입니다. 캔버스 v1(`wb-canvas`, `wb-compose`)의 문제(회색 와이어프레임 상자, 모든 엣지를 한꺼번에 그린 스파게티, 작은 글자, 처음 보는 사람이 들어갈 곳 없음, 범례 의존)를 비유 하나와 단계적 공개로 풉니다. desktop-ux 명세에 합칠 원고이고 spec.md는 고치지 않았습니다.

- 실행: `MOCKUP=wb-v2a MOCKUP_PORT=8911 mise exec -- bun run mockup`, 빌드는 `MOCKUP=wb-v2a MOCKUP_OUT=… mise exec -- bun run mockup:build`
- 상태(`?state=`): `overview`, `layer`, `detail`, `tour-1`, `tour-3`, `hull`, `diff`, `matrix`, `failure`, `compose`, `flow`, `trial`, `profile`. `?theme=dark`.
- 셸: 공용 `_shell` 그대로(`contextField` prop만 씀). 작업대 내비에서 "만들기"를 뺐습니다(사용자 결정 6).
- caustic: 바꾸지 않았습니다. 빈틈은 §8.

## 1. 비유: 층으로 된 건물, 가운데 엔진

- **에이전트 루프**가 가운데 있습니다. 개요에서는 고리, 층 보기에서는 경기장 모양 궤도입니다. 한 턴이 고리를 한 바퀴 돕니다.
- **소켓 = 확장 지점**. 궤도 위 둥근 홈입니다. 46개 지점이 7종(input · request · guard · tool · boundary · session · lifecycle)으로 묶이고, 핸들러가 걸린 지점만 소켓으로 그리고 나머지는 종류 칸의 수로 접습니다.
- **역(station)**: 궤도 위 "post 큐"와 "drive 자리". drive 자리에는 한 그룹만 앉습니다(대화마다 임대 하나).
- **위에서 꽂는 것 / 아래서 받치는 것**: 훅을 거는 블록(L3 의도 그룹, 외부 plugin)은 루프 위층에 놓이고 아래 핀을 소켓에 꽂습니다. 능력을 내주는 서비스(L2)는 루프 아래층에 놓이고 위쪽 콘센트로 능력을 내줍니다. 그 아래 L1·L0 기반, 맨 아래 F 계약 띠.
- **설치 = 블록을 자기 층에 놓고 핀을 소켓에 꽂기**. 매니페스트 `points`가 핀이 되고, `usesPost`·`usesDrive`가 post 핀(마름모)·drive 핀(네모)이 됩니다.
- **그룹 = 부품을 쌓은 묶음**. 그룹 블록 뒤에 얇은 판 둘이 비칩니다. 구성기에서 group-kit 등뼈에 부품 판을 쌓은 탑으로 펼칩니다.

## 3. 엣지 규칙

1. **기본으로 그리지 않습니다.** 연결은 소켓 아래 색 점(꽂힌 블록의 층 색, 하나에 하나)과 블록 핀으로 셉니다.
2. **그리는 때는 셋**: 고른 블록(그 블록의 엣지만), 임대(보유 = accent 굵은 선 + 흐름, 대기 = tertiary 점선), 실패(danger 점선 / warning 실선 + 이름표).
3. **직교 경로, 둥근 모서리(8)**. 블록 핀 → 아래로 → 층 사이 차선 → 옆으로 → 소켓. 차선은 블록마다 7px씩 떨어져 겹치지 않습니다(묶음).
4. **같은 곳으로 가는 여러 선은 하나로**: 구성기에서 지식 능력 셋은 선 하나 + "knowledge × 3".
5. **색은 출발 층의 ink**(L3 → 소켓은 iris, 서비스 → 소비자는 mint, L1은 slate). optional 능력은 긴 점선, requires는 실선.
6. 능력 엣지는 층 보기에서 루프를 가로지르므로 그리지 않고, 고르면 내주는 서비스에 층 색 고리 + "능력 6 · 아래 서비스에서" 이름표만. 선은 상세 단계에서 수평으로 그립니다.
7. 움직임은 셋뿐: 보유 임대의 흐름 점선, 시험의 렌즈 선 위 점, 지금 단계 고리 숨쉬기. `prefers-reduced-motion`에서 멈춥니다.

## 4. 맥락 테두리(hull)와 차이

- 맥락은 왼쪽 패널 맥락 칸 하나가 정합니다(결정 3). 대화·시험 맥락에서 그 맥락에서 켜진 블록을 **한 덩어리 테두리**로 감쌉니다. 층마다 켜진 블록을 감싼 둥근 사각형들의 합집합이고, 루프 층을 통째로 포함해 위아래가 이어집니다.
- 그리기: 면은 path 하나(nonzero, 겹친 곳 두 번 칠하지 않음, 4.5%), 테두리는 마스크 고리(합집합을 1.75px 키운 모양 − 합집합)라 안쪽 겹친 선이 없습니다.
- 색: 대화 = 잉크(accent, 1.75px), 프로필 = agent, 시험 = warning 점선 [제안]. 테두리 위 이름표: 점 + "대화 · 캐시 무효화 조사" + "실시간 · 턴 7 · 켜짐 8".
- 밖에 있는 블록은 흐리게(35%). "다음 경계에 켜짐"(pendingToggle)은 테두리 밖 점선 블록 + 메타 글.
- **차이(프로필 ↔ 대화)**: 캔버스 위 한 줄 띠("탐구 중심을 이 대화에 적용하면 + 대화 도구 · − 계획 먼저 · ~ Helm 렌즈 3 → 4 · drive 그대로 · ◇ 다음 단계 경계에 적용", [닫기] [이 대화에 적용])와 블록 표지. 켜질 블록은 diff-add 면, 꺼질 블록은 취소선, 덮어쓴 설정은 메타에 "maxLenses 3 → 4". 두 테두리를 겹치는 그림은 1280px에서 읽히지 않아 버렸습니다.

## 5. 줌 세 단계(단계적 공개)

| 단계 | 세계 | 보이는 것 | 엣지 |
|---|---|---|---|
| 1 개요 | 900×636 | 개념 다섯(의도 그룹 4, 외부 plugin 2, 서비스 5, 맥락 5, 기반 9) + 가운데 루프 고리와 소켓 7종(쓰는 수) + drive 자리 + F 띠 | 굵고 연한 리본, 관계 하나에 수 하나("꽂힘 on 12 · drive 3", "능력 9") |
| 2 층 | 900×604 | 층 바닥판 다섯, 블록, 소켓, 역 | §3 규칙 |
| 3 상세 | 780×600 | 고른 블록을 펼침: 왼쪽 루프를 세로로 편 소켓 줄(fold·실패 규칙·p95), 가운데 포트, 오른쪽 서비스, 아래 역 | 전부, 수평 |

- 오가기: 캔버스 왼쪽 아래 줌 사다리(줄이기 · [개요 | 층 | 상세] · 키우기 · 층 보기에서 "자동 배치로 되돌리기"). 개요 타일 누르기 → 층, 블록 누르기 → 고름(검사기 열림), 상세 단추 → 상세. 세계는 부모에 맞춰 줄고(0.55~1.1) 단계 사이 변환은 300ms.
- 배치는 층마다 자동입니다. 같은 층 안에서만 끌어 옮기고 기기마다 기억합니다(결정 4).
- **나눔 보기(결정 1)**: 1280(wide)에서는 캔버스 왼쪽에 블록 목록(12.5rem, 층별 묶음, 층 색 점, 상태 면). 목록과 캔버스의 고름은 양쪽으로 맞물리고 오른쪽 well은 검사기입니다. well이 열리면 목록을 접어 캔버스 폭을 지킵니다. 1000(medium)은 목록 없이 캔버스만, 700(compact)은 목록만(루프 카드를 L3와 L2 사이에 끼워 건물 순서를 지킴).
- **운영만(결정 2)**: 지도에서는 켜기·끄기, 다시 켜기, 설정 덮어쓰기만 합니다. 구조는 "구성기에서 열기"로.

## 6. "구조 살펴보기"

머리 단추 하나. 다섯 단계, 세계 위에 바탕색 74% 막을 덮고 비춘 곳만 구멍 + accent 테두리, 옆 빈자리에 설명 카드(단계 점, 이전·다음, 닫기).

1. 가운데가 에이전트 루프예요(개요, 고리)
2. 고리 위 홈이 소켓(확장 지점)이에요(개요)
3. 설치하면 블록이 자기 층에 놓여요 — Helm이 내려앉고 핀 여섯이 소켓에 꽂히는 선(층)
4. 그룹은 서비스의 능력을 불러 써요 — L3 + L2를 비춤, 꼭 필요/선택의 차이
5. 대화마다 켜는 블록이 달라요 — 맥락을 대화로 바꾸고 테두리와 drive 자리, 다음 단계 경계

## 7. 표 보기와 구성기

### 7.1 층 × 지점 행렬(머리 "표")
- 행 = 훅을 거는 확장(층 등줄 + 아이콘 면, 층 사이 틈), 열 = 지점(종류별 머리, 아무도 안 건 종류는 빗금 좁은 열). 열 머리에 꽂힌 수 막대, fold 모양, 실패 규칙(통과 · 거부 · 건너뜀).
- 칸 보기: 연결(층 tint + ink 막대) · 지연(p95/예산 열지도: well → 연한 warning → warning → danger, 칸 안 p95와 %) · 실패. 최근 실패는 칸 오른쪽 위 danger 수 배지.
- 아래 **그룹 구성 부품 목록**: 그룹마다 부품을 이어 붙인 띠(on = 층 tint, drive = 층 ink, post·기록 = neutral, 실패 부품 = danger 면). 선언 없는 그룹은 점선 "구성 정보 없음".

### 7.2 구성기(내비 "구성")
- 머리: "구성 Helm" + 메타, [복제해서 고치기] [새 그룹](결정 6) [부품 | 흐름 | 프로필].
- **부품**: 지도 상세와 같은 세 열. 왼쪽 루프 소켓 · 가운데 group-kit 등뼈에 머리 판(부품 띠) + 부품 판 일곱(슬롯 아이콘, 이름 + 슬롯, 한 줄, 연산 면) · 오른쪽 "내는 것"(공개 기록 3, post 큐, 상태 문서)과 "쓰는 능력"(에이전트·Exa·지식·작업).
- **흐름**: 단계 머신을 위 줄(오른쪽) · 아래 줄(왼쪽) 뱀 모양으로. 노드 = 커밋된 단계(임대 소모 칩), 선 위 ◇ = 단계 경계 + 조건, explore → 렌즈 자식 셋 부채꼴 → 모으기(부분 결과 허용). 쓰기 거부 구간은 회색 테두리 하나. **사람 확인**은 drive 원시(결정 8)라 converge와 apply 사이에 "넣을 수 있는 자리"로 보이고 "기다리는 동안 임대를 놓고, 답하면 다시 받아요"를 씁니다.
- **시험 실행**(흐름의 상태): 위 띠에 임대 사용량 셋과 [다음 경계에서 멈춤](결정 9: 시험 대화에서 다음 단계 경계에 실제로 멈추고 임대 유지) [한 경계씩] [replay로]. 지난 단계 체크, 지금 단계 숨쉬는 고리, 렌즈 돎(회전 + 선 위 점)·끝(발견 2)·실패(danger 면, 점선), 가드 발화 "거부 1 · bash", 아래 경계 기록 띠(◇ 줄).
- **프로필**: 층 바닥판마다 블록 카드 + [켜기 | 끄기 | 그대로]. 바뀌는 블록만 차이 표지. 오른쪽 "이 대화에 적용하면"(층별 결과 칩, drive, ◇ 다음 경계, [이 대화에 적용] [시험 대화로] [저장])과 "tool.call.before에 꽂힌 순서"(guard 고정 → user → project, 앞에서 거부하면 뒤는 불리지 않음).

## 8. 색

- **층 정체 색 [제안 원칙]**: 캔버스 안에서만 층마다 낮은 채도의 색 하나. L3 iris, plugin coral, L2 mint, X(소켓) amber, L1·L0·F slate. 쓰는 곳은 네 가지뿐입니다: 아이콘 면(tint 18~26%), 바닥판(6~8%), 핀·소켓 고리·엣지(ink = 색을 글자색에 섞음), 목록 점. 블록 면과 글자는 늘 neutral입니다.
- 섞기는 `color-mix(in oklab, …)`입니다. `in oklch`로 무채색(hue 0)과 섞으면 색상환을 돌아 iris가 분홍, mint가 올리브가 됩니다(시안에서 겪음).
- tone은 상태만: danger 자동 꺼짐·실패 엣지, warning 실패 있음·지연, accent(잉크) 임대 보유·지금 단계·고름, diff-add/remove 차이, agent 덮어씀.
- 토큰: Tailwind가 쓰지 않은 `--color-*` 테마 변수는 내보내지 않으므로 인라인 스타일과 사용자 CSS는 `--cs-color-*`, `--cs-elevation-*`를 씁니다.

## 9. 제안 원칙(DP 후보)

- **V-01 층 정체 색**: §8. DP-29의 "tone은 아이콘 면에만"을 캔버스 안에서 층 색에 한해 넓힙니다(면 tint·핀·엣지). 상태 tone과 섞지 않습니다.
- **V-02 엣지는 사건이 있을 때만**: 기본은 핀과 소켓 점으로 연결을 셉니다. 고름·임대·실패에만 선을 그립니다.
- **V-03 위에서 꽂고 아래서 받친다**: 훅은 루프 위, 능력은 루프 아래. 방향이 뜻입니다.
- **V-04 줌 단계는 정보 단계**: 개요(개념과 수) → 층(블록과 중요한 선) → 상세(포트와 검사기). 단계마다 글자 크기가 화면에서 11px 밑으로 내려가지 않게 세계 크기를 정합니다.
- **V-05 맥락은 한 덩어리 테두리**: 합집합 하나, 안쪽 선 없음. 두 맥락 비교는 테두리 둘이 아니라 차이 띠 + 블록 표지.
- **V-06 깊이는 면으로**: 블록에 테두리를 긋지 않습니다. 점선 윤곽은 "여기 없음"(꺼짐, 넣을 수 있는 자리, 선언 없음)에만.
- **V-07 둘러보기는 같은 화면 위에서**: 별도 안내 화면을 만들지 않고 실제 지도를 비춥니다.

## 10. 빈틈과 확인할 것

- caustic `[gap:C-35]` 노드 그래프 보탬: 세계 맞춤 보기(fit + 단계 줌), 직교·묶음 엣지(차선), 합집합 hull, 엣지 위 흐름 점, 블록 핀·콘센트. `NodeGraph`(efc4b3e)는 포트를 재서 곡선을 그리지만 이것들이 없어 `parts/kit.tsx`, `parts/block.tsx`, `parts/loop.tsx`에 토큰으로 그렸습니다. 재사용이 확실해지면 `packages/react`로 옮길 것을 제안합니다.
- caustic: 둘러보기 덮개(구멍 + 설명 카드) 부품이 없습니다(`parts/tour.tsx`).
- wire: 소켓 아래 점과 행렬은 확장별 `points`와 지점별 p95·예산·실패 수가 필요합니다(`ext.list` + 측정). 그룹 부품은 매니페스트 `composition` 필드(결정 7)가 필요합니다. 사람 확인 원시는 ADR-0018 승인 요청 위에 drive 쪽 기다림/임대 반납이 필요합니다(결정 8). 시험 "다음 경계에서 멈춤"은 시험 대화 전용 경계 멈춤 명령이 필요합니다(결정 9).
- 고정 데이터 정정: "탐구 중심" 프로필은 차이를 보이려고 계획 먼저 끄기·대화 도구 켜기를 더했습니다. "계획 먼저"는 구성 선언이 없는 그룹으로 두었습니다.
- 확인할 것: 대화 테두리 색을 잉크로 둘지(info는 L3 iris와 같은 색이라 쓰지 않음), plugin 판을 L3 층 오른쪽에 둔 것(훅을 거니까 위층)이 맞는지.
