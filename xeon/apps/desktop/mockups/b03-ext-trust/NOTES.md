# B03 확장 가져오기와 신뢰 — 메모

## 범위

coverage-v2 O-10, N-37, N-38, §4-2(다시 확인), §4-12(URL 설치는 안내만). 진입점은 크래프트 "확장"(P-13)의 머리 "가져오기", 행 업데이트 단추, 행 메뉴 "지우기"입니다. 목록 자체(P-13)는 진입점만 남기고 줄였습니다.

## 레이아웃 결정

- 모든 확인은 `Dialog kind="alert"`이고 기본 초점은 거절 쪽("취소", "0.3.0 그대로 쓰기")입니다. 상세는 DP-12처럼 `ListDescription`(ghost, xs) 한 목록입니다.
- 신뢰 확인 행 순서: 확장 → (프로젝트 신뢰) → 요청한 수준 → 위치 상한(+경로) → 실제 수준(굵게) → 쓰는 연산 → 훅(꾸밈 없는 글자, DP-31) → 자체 코드 화면(경고 tone 아이콘 면 + "자체 화면 코드를 실행해요" + `frame.reason` 인용). 실제 수준 = min(위치 상한, 요청)이라 둘이 같아도 셋 다 보입니다.
- 프로젝트 확장은 폴더 신뢰(O-04 allow)가 먼저입니다. 아직이면 "켜기"를 잠그고 행 안 "폴더 신뢰…"로 보냅니다.
- 다시 확인은 늘어난 것만 행으로 두고 각 행에 `Badge tone="warning"` "늘어남", 그대로인 것은 연한 한 줄입니다. 줄어든 변경은 대화 상자 없이 목록 위 런타임 한 줄입니다.
- 가져오기 검사는 로더 앞 단계와 같은 여섯 가지(확장 정보 파일, 이름 겹침, 수준 요청, 훅, 화면 기여, 파일 경로)이고 진단 코드(`name_conflict`, `trust_exceeds_source`, `frame_reason_missing`)를 회색 mono로 붙입니다. 실패는 목록 바로 위 `Alert` 하나입니다(DP-28).
- 지우기는 O-06 모양에 쓰는 프로필, 플러그인 화면, 확장 저장 데이터(테이블과 행 수, "저장 데이터도 지우기" 기본 꺼짐)를 더했습니다. 기록(이벤트)은 남는다고 설명 한 줄에 둡니다.

## caustic

`Dialog`, `ListDescription`, `RadioGroup`(점 + 굵기, DP-44), `FileUpload`(웹), `Input`, `Menu`, `Alert`, `Badge`, `Checkbox`, `Skeleton`, `Button`, `IconButton`, `Tooltip`, `Toaster`, `_shell` `ToneIcon`.
