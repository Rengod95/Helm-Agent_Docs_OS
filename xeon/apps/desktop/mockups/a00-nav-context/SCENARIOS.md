# a00-nav-context 시나리오

셸 내비 정합(S-01), 보기 기준 칸(N-01), 대화 목록 테스트 표지(N-04), 테스트 대화 정리(계획에 없음 4)를 눌러 봅니다. `?dev=1`이면 왼쪽 아래 시나리오 막대와 "다음에 누를 것" 한 줄이 보입니다.

이 폴더의 상태는 셸 상태(영역, 보기 기준, 패널)라 `&step=`을 쓰지 않습니다. 시나리오의 주요 순간은 같은 모습의 `?state=`로 찍습니다(아래 "순간" 열).

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 순간(?state=) | 근거 |
|---|---|---|---|---|
| `context-pin` | ① 대화 영역에서 다른 대화를 열고 크래프트로 감 → ② 대화로 돌아와 런타임 탭 "크래프트에서 보기" → ③ 대화 영역에서 다른 대화를 엶 → ④ 크래프트에서 자물쇠를 누름 | ① 기준 칸이 연 대화를 따라감(열린 자물쇠) ② 크래프트로 가며 기준이 그 대화로 고정(닫힌 자물쇠, 토스트) ③ 고정이라 기준이 그대로 ④ 고정 풀림, 다시 따라감 | `chat`, `wb-follow`, `wb-pinned` | 결정 11, spec §4.9.3, §4.9.5 |
| `context-pin-lost` | `context-pin`의 ②까지 | 3.5초 뒤 고정한 대화가 다른 창에서 닫힘 → 기준이 "전체"로 바뀌고 경고 토스트, 목록에서 대화가 빠짐 | `wb-all` | 실패 갈래(정리 규칙 [제안]) |
| `trial-cleanup` | 왼쪽 "테스트" 묶음 끝 "끝난 테스트 1개 지우기…" → 확인 대화 상자 "지우기" | 확인 상자(지울 테스트, 프로필·대상, "결과는 크래프트 테스트 실행에 읽기 전용으로 남아요") → 목록에서 끝난 테스트가 빠지고 토스트 | `cleanup-confirm`, `cleanup-done` | 계획에 없음 4, N-04 |
| `trial-cleanup-busy` | `trial-cleanup`과 같음 | 한 테스트가 다른 창에서 열려 있어 남고 경고 토스트("그 창을 닫고 다시 지워 주세요") | `cleanup-partial` | 실패 갈래 |

## ?state= 목록

| id | 모습 |
|---|---|
| `chat`(기본) | 대화 영역: 주 내비 다섯(연결 포함), 폴더 안 "테스트" 묶음(실행 중 1 · 멈춤 1 · 끝남 1), 런타임 탭 |
| `wb-follow` | 크래프트, 기준 = 대화(따라감, 열린 자물쇠), 내비 여섯 |
| `wb-pinned` | 크래프트, 기준 = 대화(고정, 닫힌 자물쇠) |
| `wb-all` | 기준 = 전체: 설치된 확장 전부와 자동 꺼짐 Alert |
| `wb-profile` | 기준 = 프로필 "탐구 중심": 적용했다면 바뀌는 칸에만 → 표시, "프로필 고치기" |
| `wb-trial` | 기준 = 테스트 "렌즈 5개로 넓히기": 테스트가 덮어쓴 칸 표시 |
| `wb-picker` | 기준 칸 펼침: 전체 · 대화 · 프로필 · 테스트 네 묶음 |
| `wb-closed` | 왼쪽 패널 닫힘: 머리 오른쪽에 "보기 기준 · 대화 캐시 무효화 조사"(누르면 패널이 열리고 칸에 초점) |
| `cleanup-confirm` | 끝난 테스트 지우기 확인 |
| `cleanup-context` | 확인 상자 + "크래프트 보기 기준이 이 테스트라 전체로 바뀌어요" |
| `cleanup-done` | 지운 뒤 목록과 토스트 |
| `cleanup-partial` | 실패: 한 테스트는 남김 |
| `narrow` | 390px: 왼쪽 패널이 떠 있는 시트, 테스트 표지 유지 |
| `narrow-wb` | 390px 크래프트: 패널이 닫혀 머리의 "보기 기준" 글이 기본 진입 |
