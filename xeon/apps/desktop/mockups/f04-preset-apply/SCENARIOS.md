# f04 프로필 적용 · 시나리오

`?scenario=<id>`(`&dev=1`이면 막대), `&step=<n>&hold=1`은 그 단계에 멈춘 모습. 스크린숏 `sc-<id>-<n>.png`.

| 시나리오 | 누르는 순서 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `apply-ok` | "이 대화에 적용" → (기다림) | 0 지금 · 적용하면 → 1 상태 칸 "이번 단계가 끝나면 적용", 적용하면 흐림, 단추 진행 중 → 2 적용 전 · 지금(soft 채움), "대화로 가기" | W-46, SC-21 |
| `apply-rollback` (실패) | "이 대화에 적용" → (기다림) → "다시 적용" → (기다림) | 2 Alert "비용 라우터를 켜지 못해 모두 되돌렸어요", 지금 · 적용하려던 값(취소선) · 결과(그 줄만 danger 점 + "필요한 기능 기다림") → 3 기다림 → 4 적용함 | W-46 원자적 되돌림, Y10 |
| `preview-retry` (실패) | "리뷰 다시 켜기" → (기다림) | 0 Alert + 적용하면 열 빗금, 리뷰 행 danger 점, 적용 잠금 → 1 적용하면 칸에 글자 자리 → 2 미리 보기(리뷰 행 없음, 적용 풀림). "다시 미리 보기"만 누르면 다시 실패로 돌아옵니다 | W-44, c01 `new-preview-fail` |
| `compose-fix` (실패) | "이 대화에 적용" → (기다림) → 비용 라우터 "그대로" → "다시 적용" → (기다림) | 2 구성기 위 Alert, 고른 값 유지, 그 줄 적용 뒤 칸에 원인 → 3 표지 사라짐 → 4 고르기 잠금, 진행 중 → 5 지금 칸이 새 값, 바뀐 확장, "대화로 가기". 그대로 다시 적용하면 또 되돌아옵니다 | §6.28.3, W-46 |

`apply-reverted`의 "프로필 고치기"는 `apply-compose-reverted`로 옵니다. 왼쪽 내비 구조·구성은 두 입구의 미리 보기로 갑니다.

## `?state=` 목록

`apply-reverted`(기본), `preview-fail`, `apply-pending`, `apply-done`, `apply-compose-reverted`.
