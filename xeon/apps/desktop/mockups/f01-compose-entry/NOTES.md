# f01-compose-entry 메모

P-21 구성기로 들어오는 길입니다(C-6, C-7, C-8, spec §6.28, §6.29). 블록, 캔버스 호스트, 코드 보기, 데이터는 `wb-compose`에서 가져옵니다. 흐름 판(`parts/flow-board.tsx`)은 `f02`와 함께 씁니다.

## 레이아웃 결정

- "새 그룹"은 머리의 동작입니다. 만들기 내비가 없습니다. 고른 그룹 `Select`와 나란히 둡니다.
- 시작점은 선 격자 한 장입니다. Helm 복제와 플러그인 빌더 종류가 같은 무게이고, 준비 중은 고를 수 없습니다.
- 플러그인 빌더로 만들기와 플러그인 빌더 켜기는 같은 자리, 같은 solid입니다. 꺼진 동안 쌓은 블록은 그대로 둡니다.
- 사람 확인 노드에는 배지가 없습니다. 둘째 줄이 주도 반납을 말합니다. 테스트가 기다릴 때만 warning 점입니다.
- 구성 정보 없음과 단계 선언 없음은 일부러 비어 있습니다. 훅 이름으로 블록을 지어내지 않습니다.

## 제안: 코드 보기에서 파일 만들기로

`wb-compose` 코드 보기는 명령 복사 동작이 빠진 뒤 다음 길이 없습니다. 코드 보기 아래에 한 줄을 둡니다(`code-forward*`, 제안).

| 조건 | 문장 | 동작 |
|---|---|---|
| 플러그인 빌더 켜짐 | 아직 파일이 없어요. 대상 폴더에 만들고 검사해요 | 플러그인 빌더로 만들기 |
| 플러그인 빌더 꺼짐 | 켜면 여기서 바로 만들 수 있어요 | 플러그인 빌더 켜기 |
| 엔진 없음 | 연결되면 여기서 만들 수 있어요 | 엔진 보기 |

만든 뒤에는 §6.29의 다음 동작(테스트 대화에서 켜기, 편집기에서 열기, 사용자 확장 위치에 연결, 잠긴 다시 돌려 검사)이 같은 자리에 옵니다. 자동 재생은 없습니다.

## 문서와 어긋나는 곳

- spec §6.28.5, §6.29: 아직 명령 복사를 대안으로 적습니다. 제품 표면이 아니므로 이 제안으로 바꿔야 합니다.
- spec §6.28.2, DP-56: "런타임에 없음" 배지. P-21 지시대로 뺐습니다.
- spec §6.29의 이름 규칙은 예약 이름 23개입니다. 시안에는 일부만 넣었습니다.

## 빈틈

- 좁은 폭(개요 편집기, `LayerTree`)은 그리지 않았습니다. 이 폴더의 상태에 없습니다.
- 흐름 판 끝 노드는 편집에서 결과 다섯, 테스트에서 한 노드입니다. 계기 열에 폭을 내주려고 접었습니다.
