# B02 대화 영역의 플러그인 기여 — 시나리오와 상태

대화 화면(P-02) 위에서 확장이 기여하는 네 자리(옆 패널 `well`, 대화 카드 `card`, 상태 칸 `status`, 명령 `command`)를 눌러 볼 수 있게 했습니다. `?scenario=<id>&step=<n>`(0부터), `?dev=1`이면 시나리오 막대가 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `slot-overflow` | (자동) 확장 둘이 켜짐 → 막대 끝 "더 보기" → "턴 비용" | 플러그인 탭 5 → 6 → 7. 일곱째부터 "더 보기" 메뉴(표시 이름 + 회색 id)로 감. 고르면 그 well이 열림. 실패 갈래: 잠시 뒤 검토가 자동으로 꺼져 그 탭·상태 칸·명령이 빠지고 넘침이 풀림(토스트 "확장 상세") | ADR-0021 §3.2 well 상한, spec §4.9.4, N-21 |
| `card-more` | (자동) 답이 스트리밍됨 → 탐구 결과 카드 "더 보기" → "탐구 화면 열기" | `helm/finished` 카드가 높이 320에서 잘리고 흐림 + "더 보기". 누르면 같은 확장의 well이 열림. 실패 갈래: 다음 레코드(`x.acme-notes.note.pinned`)의 카드를 그리지 못해 일반 항목 한 줄("카드를 그리지 못해 기본 모양으로 보여요 · 모르는 위젯")로 보임 | ADR-0021 §3.2 card, §3.10, spec §6.25 슬롯 규칙, N-22 |
| `status-command` | (자동) 상태 칸 글이 바뀜 → Helm 상태 칸 눌러 Popover → 찾기 칸(팔레트) "탐구 멈춤" | 상태 칸 "탐색 1/3 렌즈" → "탐색 2/3 렌즈" → "수렴 · 발견 2", 대화 머리 런타임 줄도 같은 글. Popover에 플러그인 트리와 `ext:helm`. 팔레트 "플러그인" 묶음(확장 id 연한 mono). 멈추면 칸 "멈춤 · 발견 2". 실패 갈래: 검토가 자동으로 꺼져 그 상태 칸과 팔레트 명령이 사라짐 | ADR-0021 §3.2 status·command, spec §4.5, §6.30, N-23, N-24 |

## `?state=` 목록

| id | 상태 |
|---|---|
| S1 | 기본: Helm well(기본 부품), 카드 셋, 상태 칸 둘(Helm 단계, 검토 대기 24자 자름 + warning 점) |
| S2 | 자체 코드 well(흐름판): 폭 400, 왼쪽 끝 폭 손잡이(320~480), "자체 코드 화면" 표지 + 상자 |
| S3 | 옆 패널 8개 → 6개 + "더 보기" 메뉴 2개 |
| S4 | 열린 대화 없음: 플러그인 탭·상태 칸·문맥 칸 없음(DP-45) |
| S5 | 긴 대화 카드: 320에서 자르고 "더 보기" |
| S6 | 카드 그리기 실패 → 일반 항목 |
| S7 | 상태 칸 Popover(검토) |
| S8 | 팔레트 "플러그인" 묶음 |
| S9 | 꺼진 확장(검토) 명령 숨김 |

- 좁은 폭: S1을 1000px(well이 뜨는 시트, 상태 칸은 진행권 그룹 하나만), 700px(compact 상태 표시줄, 플러그인 칸 없음)로 찍었습니다.
