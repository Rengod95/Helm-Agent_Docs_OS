# c04-settings-rows 메모

p09-settings는 고치지 않고 공용 틀 `../_settings`(SettingsFrame, SettingRow, SettingSection)를 그대로 써서 행만 더했습니다. 다른 탭을 누르면 p09-settings로 옮깁니다.

## 레이아웃 결정

- 넣은 자리: 프레임·묻지 않기·계측·개발 모드·확장 설정은 "플러그인과 그룹" 탭 안 구역 넷, 언어는 "외관" 탭 "언어와 지역" 구역. 계측(`x.operations.*`)은 확장 연결부(X) 키라 플러그인 탭에 두었습니다. 개발 모드는 `l3.authoring.*`라 "만들기와 테스트" 구역입니다.
- 행 배지는 하나(DP-36): 범위는 중립 배지, 적용 시점은 연한 글, "다시 시작하면 적용"만 warning 배지(그때 범위 배지는 숨기지 않고 오른쪽에 둠).
- "묻지 않기" 목록은 SettingRow 모양의 그룹: 동작 이름 + 확장 표시 이름, 둘째 줄 화면 id mono, 범위 글, "다시 묻기". 승인이 필요한 동작은 이 목록에 들어올 수 없다는 한 줄.
- 계측 비용 문장은 숫자 추정 + "실제 값은 성능 측정 뒤 이 자리에"(Y17).
- 언어: 데스크톱은 화면 트리를 바로 다시 그리므로(L4.desktop §18) 화면 글은 즉시, 앱 메뉴·트레이·OS 알림만 다시 시작 뒤입니다. 시안은 한국어 그대로 두고 배지·도움말로만 보였습니다.

## caustic 부품

`Switch`, `NumberField`, `Select`, `Input`, `Badge`, `Button`, `Toaster`(action). 공용 틀 `_settings`.

## 빈틈

- 저장 중 표시: SettingRow에 "저장 중" 상태가 없어 컨트롤 옆에 스피너를 붙였습니다.

## 웹·좁은 폭

- 720 아래: 탭 열이 머리 `Select`(공용 틀), 묻지 않기 줄은 범위 글을 숨김.
- 웹: 개발 모드 행은 원격 호스트 값을 읽기만 합니다.
