# a03-authoring 시나리오

대화에서 제작(L3 authoring)을 눌러 봅니다: 진행 표시(N-08), 사람 확인 카드 다섯(N-09), 결과 카드(N-10), 쓰기 범위 거부(N-11), "제작" well과 화면(N-12), 꺼짐·준비 중·안전 모드·개발 모드 필요(N-13). 상태와 시나리오는 `flow.ts`의 상태 기계 하나입니다(`?state=` = 대본 앞 n개 동작, `?scenario=<id>&step=<n>`, `&hold=1`이면 그 순간에서 멈춤). 확인 카드에서는 시간표가 멈추고 사용자를 기다립니다. `?dev=1`이면 시나리오 막대와 다음에 누를 것이 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `authoring-happy` | (요청이 자동으로 들어감) → 확인 1 "답하기" → 확인 3 "테스트하기" → 확인 4 "묶기" → 결과 카드 "사용자 확장 위치에 연결" → 확인 5 "연결" | 런타임 줄이 단계 사슬(요구 정리 › 구성 초안 › 뼈대 › 검사 › 테스트 › 묶기, 지금 단계 굵게), 단계마다 런타임 행(`grp:authoring`), 확인마다 "사람 확인을 기다려요 · 주도 반납" → 답하면 "다시 받음", 테스트 대화 행("보기"), "다시 돌려 검사는 개발 모드에서만 · 건너뜀", 결과 카드, 연결 뒤 "꺼진 채로 · 켜려면 신뢰 수준 확인", "authoring이 주도를 놓았어요 · 제작 끝" | authoring §4.1, A-4, 결정 캔버스 8, 결정 10 |
| `authoring-fix-limit` | (기다림) → 확인 2에서 "여기서 멈추기" | 실패 갈래: 검사 오류 AU-003 → 고치기 1/3, 2/3, 3/3(경고) → 확인 2 "고치기 한도 3/3" → 멈추면 "제작을 멈췄어요 · 파일 9개는 남겨요" + "폴더 열기" 행 | authoring §4.1(같은 오류 3번), §6 `fixLoopLimit` |
| `authoring-scope-denied` | (기다림) | 실패 갈래: 뼈대 뒤 에이전트가 `group-sdk/src/define.ts`를 고치려다 거부됨: 실패 도구 행(`denied: write_scope`), danger 런타임 행 "쓰기 범위 밖이라 막았어요", 에이전트가 대상 폴더 안에서 다시 함 | authoring §4.2, A-3 |
| `authoring-off` | 런타임 행 "플러그인 빌더 켜기" | 꺼져 있을 때 첫 사용: 에이전트 한 문장 + core 행 "플러그인 빌더(authoring) 꺼짐 · 내장 그룹"(동작 하나) → 켜면 "이 대화에서 · 다음 단계 사이에 적용" 뒤 제작 시작 | authoring §3.1(기본 꺼짐), spec §12.1 30번 |
| `authoring-blocked` | 확인 1에서 관찰 그룹 고르기 | 실패 갈래: X 훅 요청 → "종류 x.hook은 준비 중이에요" 경고 행 → 대안(group.observe) 확인 카드 | 카탈로그 `blocked`, §3.4 |
| `authoring-frame` | `authoring-happy`와 같음 | 결과 카드의 화면 방식이 "자체 코드 화면 · 전체 화면 frame.reason"과 이유, AU-008 정보 | 결정 1(화면 방식은 에이전트가 고름) |
| `authoring-dev-required` | 결과 카드 "다시 돌려 검사"(잠김 아이콘) | 실패 갈래: 경고 행 "다시 돌려 검사는 개발 모드에서만 돌아요 · dev_mode_required" + "개발 모드 설정 보기" | 결정 4, 10, A-5 |

- 진행 중 아무 때나 입력창의 중단(■) = `/author stop`: "제작을 멈췄어요 · 만든 파일은 남겨요"(`?state=stopped`).
- 스크린숏 순간: `sc-happy-4`(확인 1), `-9`(테스트), `-14`(결과), `-16`(연결 끝), `sc-fix-limit-10`(고치기 3/3), `-13`(멈춤), `sc-scope-denied-8`, `sc-off-3`, `-6`, `sc-blocked-5`, `sc-frame-14`, `sc-dev-required-15`.
