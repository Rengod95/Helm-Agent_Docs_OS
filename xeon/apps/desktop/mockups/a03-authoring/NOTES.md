# a03-authoring 메모

대화 "아침 요약 그룹 만들기"에서 플러그인 빌더가 `daily-digest`(group.drive)를 만드는 흐름입니다. 제작은 별도 마법사 화면이 아니라 대화 안의 drive 그룹입니다: 주도를 쥐고 단계를 돌고, 사람 확인에서 주도를 놓습니다(L3.authoring.spec §4.1, 결정 캔버스 8).

## 레이아웃 결정

- 진행(N-08): 머리 런타임 줄이 단계 사슬입니다(지금 단계만 굵게, 나머지 tertiary, 고치기 중이면 "검사 2/3"). 머리 제목 옆 "제작" Badge 하나로 이 대화가 제작 대화임을 보입니다. 단계마다 트랜스크립트에 런타임 행 한 줄(출처 `grp:authoring`).
- 확인 다섯(N-09): 고르기가 있는 것(종류와 이름, 고치기 한도)은 표준 질문 카드, 쓰기·비용이 걸린 것(테스트 비용, 묶기 전, 연결 전)은 표준 승인 카드(`AgentRequest` permission + `ListDescription`, DP-12)입니다. 제작 전용 카드 모양을 따로 만들지 않습니다. 묶기 전 카드는 경고 AU 코드, 빼는 파일, 파일 목록과 SHA-256(짧게)을 한 목록에 둡니다.
- 결과(N-10): card slot `authoring/result`. 셸 틀(확장 이름 mono + "제작 화면")과 확장 트리(제목, 메타 한 줄, `ListDescription`: 화면 방식·제작 검사·테스트·다시 돌려 검사, 동작 줄)입니다. 화면 방식은 에이전트가 고른 것과 그 이유 한 줄을 보입니다(결정 1): 선언형이면 "목록과 버튼뿐이라 기본 부품으로 충분해요", 프레임이면 `frame.reason`과 AU-008 정보.
- 동작: 주 동작 "테스트 대화에서 켜기"(solid), "편집기에서 열기"(웹·원격은 "경로 복사"), "사용자 확장 위치에 연결"(누르면 확인 5), "다시 돌려 검사"는 끝에 잠금 아이콘과 툴팁(개발 모드에서만). 누르면 `dev_mode_required` 행(결정 4, 10: 자동 replay 없음).
- 쓰기 범위(N-11): 실패한 도구 행(출력 `denied: write_scope`) + danger 런타임 행 하나. 에이전트 문장으로 다음 행동을 말합니다.
- "제작" well(N-12): 세로 `Stepper` + 요약 목록(종류, 대상 폴더, 검사, 테스트, 다시 돌려 검사). "크게"는 크래프트 플러그인 화면 `authoring/session`(가로 Stepper, AU 표, 요약, 머리 동작 "대화로" 하나, DP-42).
- 꺼짐·준비 중·안전 모드(N-13): 모두 트랜스크립트의 한 줄(core 행 + 동작 하나)입니다. 꺼짐 "플러그인 빌더 켜기", 안전 모드 "안전 모드 끄기…", 준비 중은 경고 행 + 대안 질문 카드.

## caustic 부품

`AgentRequest`(permission, 기록), `ListDescription`, `Card`·`ChoiceGroup`(공용 `QuestionCard`), `Stepper`(가로·세로), `Tooltip`, `Badge`, `Button`(iconStart), `ToolCall`(p02 ToolRow), `Toaster`, `Composer`.

## 빈틈

- 결과 카드의 "더 보기" 자리를 "제작 화면"으로 바꿨습니다(같은 확장의 page 기여로 가는 것이라 DP-24와 같음).
- 단계 사슬은 caustic `Stepper`가 한 줄 글자 모양을 지원하지 않아 글자로 짰습니다(`RuntimeChain`). 좁은 폭에서는 말줄임됩니다.
- 테스트 대화 행의 "보기"는 a01 테스트 대화로 가는 자리입니다(목업에서는 동작 없음).
- 안전 모드에서 플러그인 빌더의 대체 경로가 없습니다(CLI 제외 결정). 커버리지 §5 11번 제안(구성기 초안 저장만 허용)을 따릅니다.

## 웹·좁은 폭

- 웹·원격: "편집기에서 열기"와 "폴더 열기" 대신 "경로 복사"와 한 줄 안내(`result-web`).
- 390px: 확인 카드의 파일 목록은 해시가 다음 줄로 내려가고, 런타임 줄의 단계 사슬은 말줄임됩니다(`narrow`). "제작" well은 시트입니다.
