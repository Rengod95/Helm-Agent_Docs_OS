# 크래프트 캔버스 v3 (wb-v3)

v2 A(층 건물·고리 그림)와 v2 B(플러그인 하위 캔버스) 가운데 사용자가 좋다고 한 것을 합치고, 싫다고 한 것을 고친 시안입니다. 근거는 `_notes/pages-brief.md` "Canvas v3 round", 캔버스 결정 9개, `m4-decisions.md`, 용어 점검(`_notes/terms-and-coverage.md` 1부)입니다. 이 문서는 desktop-ux spec에 합칠 제안입니다.

- 실행: `MOCKUP=wb-v3 bun run mockup`, `?state=<id>`, `?theme=dark`
- 2026-11-01 디자인 언어 개편: 지도 보기(층 캔버스)와 그림 보기(턴 흐름 일러스트)를 뺐습니다(사용자 결정). 구조 화면은 층 × 단계 선 격자 표 하나입니다. `_art` 그림은 더 쓰지 않습니다.
- 2026-11 롤백: 배치는 개편본 그대로(선 격자 표, 빗금 빈 칸, 십자 표식, 구역 선, 화면 열두 개), 색·글자·반지름·그림자는 옛 언어 토큰입니다. 레일(페이지 세로선)·점선 구분·그라디언트·층 색·그림은 쓰지 않습니다.

| v2에서 받은 의견 | v3에서 한 일 |
| --- | --- |
| B의 플러그인 상세(구성과 흐름)가 좋음 | 가장 힘준 화면으로 키움. 플러그인 경계 판, 관련 선만 진하게, 단계 고르면 블록이 밝아짐(§5.4) |
| A의 X 고리 그림이 직관적 | [개편] 그림 보기는 뺐습니다. 턴 흐름 단계는 표의 열 순서로 남습니다(§5.1) |
| 플러그인이 다른 층과 어떻게 얽히는지 안 보임 | 포커스: 표에서 관계 없는 이름을 낮추고, 표 아래에 관계 목록(§3) |
| L0, L1, X도 바꿀 수 있다는 게 안 보임 | 층 이름을 누르면 그 층에 깔린 것 전부와 "<명사> 더하기". L1 비용 라우터, L0 build-box, X 외부 훅 둘(§5.2) |
| 용어가 어색함 | 용어 표(§1), 화면은 추천안으로 |
| 맥락·프로필이 어려움 | "보기 기준"과 "프로필"으로 이름을 바꾸고, 보기 ≠ 바꾸기를 모양으로 나눔. 첫 설명 덮개(§4) |

## 1. 용어

원칙은 용어 점검 1.5절을 따릅니다. 대화 영역은 일상어만 씁니다. [개편] 크래프트도 한국어 라벨만 두고 mono id는 화면에 내지 않습니다(상세 그림의 기능·훅 이름은 예외로 남김). 비유어(소켓, 건물, 역)는 화면 라벨로 쓰지 않습니다.

## 2. 시각 언어

[개편 2026-11-01] 배치는 개편 디자인 언어의 선 격자 방식을 따릅니다. 롤백 2026-11: 색·글자·반지름·그림자는 옛 언어 토큰으로 그리고, 이전의 층 색(V3-03), 타일 그림자, 일러스트, 세계 맞춤, 그라디언트는 뺐습니다.

- **선 격자.** 구조 표와 차이 표는 `_shell/line-grid`의 `LineGrid`(목업 안 이식본, 선 방식)입니다. 칸 사이 간격 0, 1px 선, 바깥 모서리와 묶음 경계에만 "+". 바깥 1px 틀은 `LineGridFrame`이 긋습니다(레일이 없으므로). 이 시안은 X 행 앞에 묶음 경계를 둡니다.
- **칸 안.** 플러그인 이름 글자만 씁니다. 점은 손볼 상태에만(자동 꺼짐 = 위험, 실패 있음 = 주의, 미리보기에서 켜질 것 = 중립). 훅 수·지연·색칠은 쓰지 않습니다. 빈 칸은 빗금입니다.
- **색.** 중립 우선. 고른 칸·행·열은 옛 `neutral-soft` 채움, 상세의 고른 블록·단계는 accent 1px 안쪽 고리입니다.
- **카드.** 옛 surface 카드: 표면 채움 + 1px 안쪽 테두리, 반지름 16. 그림자는 떠 있는 덮개(설명·더하기 시트, 알림)에만 `shadow-3`을 씁니다. 행 구분은 1px 얇은 선입니다(점선 아님).

## 3. 포커스와 관계

### 3.1 들어가는 길

- 표 아래 고른 것 구역의 플러그인 행을 누릅니다.
- 표 칸 안의 플러그인 이름을 누릅니다.
- [개편] 포커스 띠·렌즈 선은 없습니다. 표 아래 구역이 그 플러그인으로 바뀝니다: 이름 · 한 줄 · [닫기] [구성과 흐름].

### 3.2 무엇을 보여 주나

- 표: 포커스한 플러그인과 관계 있는 플러그인 이름만 보통 글자, 나머지는 muted입니다(디자인 언어 §7 포커스 렌즈).
- 구역: 관계 목록. 행 = 사람 말("학습이 발견 기록을 읽어요"), 끝 = 층 이름. mono id는 쓰지 않습니다.

| 층 | 관계 | Helm 예 |
| --- | --- | --- |
| L3 | 나를 쓰는 그룹 | 학습이 발견 기록을 읽어요 |
| L2 | 가져다 쓰는 기능, 지금 주는 플러그인 | 웹 검색 · Exa 검색이 줘요 |
| L1 | 쓰는 핵심 서비스 | 렌즈를 보조 에이전트로 |
| L0 | 쓰는 시스템 | 상태·발견 저장 |
| X | 끼어드는 훅 | 도구 · 쓰기 막기 |
| F | 지키는 규약·선언한 이름 | 그룹 기록 두 종류 |

사용자 L1 플러그인(비용 라우터)은 "provider 등록 · 역할 표", "모델 요청 · 모델 바꾸기", "Helm 렌즈가 route/auto로 불려요", "기록 종류·설정 키 선언"을 보입니다. 그 밖의 플러그인은 훅 표에서 X·F 관계만 끌어냅니다(실제 앱은 매니페스트 `requires`·`optional`·`provides`와 X-15 훅 등록에서 만듭니다).

## 4. 보기 기준과 프로필

### 4.1 모델

| | 보기 기준(옛 맥락) | 프로필(옛 프로필) |
| --- | --- | --- |
| 한 줄 | 지금 어느 런타임을 보고 있나 | 저장해 둔 켜기·끄기 묶음 |
| 값 | 설치 전체 · 대화(실시간) · 테스트 대화 · 프로필(설계도로 보기) | 이름 있는 스위치 묶음 + 설정 덮어쓰기 |
| 바뀌는 것 | 크래프트 모든 화면이 보여 주는 것만(결정 3) | 고른 대화의 켜짐·꺼짐(적용할 때만) |
| 모양 | 눈 아이콘 · 회색 글 · 왼쪽 위 칸 | 슬라이더 아이콘 · accent 면 · "이 대화에 적용" 버튼 |
| 저장 | 기기별 마지막 값, 대화 영역을 따라감(결정 11) | 런타임 설정(CLI·서비스와 공유, 결정 5) |

### 4.2 보기와 바꾸기를 가르는 규칙

- 보기 기준을 바꾸는 동작은 아무것도 바꾸지 않습니다. [개편] 칸 아래 설명 줄은 뺐습니다. 처음 설명 덮개가 한 번 말합니다.
- 대화를 보는 중에 칸에서 프로필을 고르면, 보기 기준은 대화 그대로 두고 **바꾸기 미리보기**를 엽니다. 표 위 카드 한 장: "프로필 '탐구 중심'을 이 대화에 적용하면" · "켜짐 3 · 꺼짐 1 · 설정 1" · [닫기] [나란히 비교] [이 대화에 적용].
- 표는 적용한 뒤 모습을 그립니다. 켜질 것은 이름 앞 중립 점, 꺼질 것은 취소선입니다.
- "나란히 비교"는 차이 화면입니다. 구조 표와 같은 선 격자로, 행 = 바뀌는 플러그인(층 경계에 "+"), 열 = 지금 · 적용하면. 바뀌는 행만 둡니다.
- 바꾸는 동작의 문구는 늘 "이 대화에 · 이번 단계가 끝나면"을 포함합니다.

### 4.3 처음 설명

보기 기준 칸 옆 `?`를 누르거나 처음 크래프트를 열면 덮개가 뜹니다. 글만 둡니다(그림 없음): 종류 넷(설치 전체 · 대화 · 테스트 대화 · 프로필)의 목록과 두 카드 "보기"(바꿔도 런타임은 그대로) · "바꾸기"(켜기·끄기와 프로필 적용만 런타임을 바꿈). 버튼은 "대화로 보기"와 "알겠어요"입니다.

## 5. 화면과 상태

내비 "구조"(옛 개요·런타임 지도) 하나에 층 × 단계 표 하나를 두고, 플러그인 상세와 차이 화면이 그 아래에 있습니다. 보기 전환(그림 | 층 | 표)은 없습니다. 왼쪽 패널, 오른쪽 떠 있는 막대와 well(받은 요청·기록·대화)은 셸 그대로입니다.

### 5.1 구조: 층 × 단계 표

- 행 = 층 다섯(그룹 · 기능 · 에이전트 코어 · 시스템 · 확장 런타임). 계약(F)은 플러그인이 없어 행이 없습니다.
- 열 = 턴 흐름 단계 일곱(대화 · 입력 · 모델 요청 · 안전 검사 · 도구 · 단계 · 수명), 흐름 순서입니다.
- 칸 = 그 층에서 그 단계에 훅을 건 플러그인 이름. 아무도 없으면 빗금입니다.
- 고르기: 칸을 누르면 칸, 단계 이름을 누르면 열, 층 이름을 누르면 행을 고릅니다. 표 아래 구역이 고른 것을 보입니다.
  - 칸: "<층> · <단계>" + 단계 설명 + 그 칸의 플러그인 목록.
  - 열: 단계 이름 + 설명 + 그 단계에 끼어드는 플러그인 목록.
  - 행: 층 이름 + "이 층이 해 주는 일" + 그 층에 깔린 것 전부(훅이 없는 내장·어댑터 포함) + "<명사> 더하기".
- 보기 기준이 대화면 그 대화에서 켜진 것만 칸에 둡니다.
- 실패 상태는 표 위 Alert(soft, 위험) "리뷰가 연속 5번 실패해 자동으로 꺼졌어요." + [다시 켜기] [기록 보기]입니다.

### 5.2 층마다 바꿀 수 있음

- 층 행을 고르면 내장과 내 것을 한 목록에 둡니다. 행 끝 글은 손볼 상태(자동 꺼짐 · 실패 있음 · 꺼짐)와 설치 출처(사용자 설치 · 이 프로젝트)만 씁니다.
- 내 것 예: L3 렌즈 리뷰(Helm 복제), L2 Exa 검색, acme 노트(프로젝트), L1 **비용 라우터**, L0 **build-box 원격**(exec 대신), X **시크릿 검사**·**끝나면 알림**(외부 훅).
- 구역 머리 동작이 "<명사> 더하기"입니다(그룹 · 기능 · 플러그인 · 어댑터 · 훅).

### 5.3 에이전트 코어(L1)에 더하기 · 시작

에이전트 코어 행의 "플러그인 더하기"를 누르면 오른쪽 시트가 열립니다. 시트: 단계 셋(Stepper: 가져오기 · 검사·신뢰 · 켜기), "이 층에서 할 수 있는 것"(provider 등록, 요청·도구 훅 훅, 도구 등록 / 주도는 그룹만), "어디서 가져올까요"(ChoiceGroup: 만들기 도우미 · 폴더 · 설치된 것 복제). 그림과 설명 줄은 뺐습니다.

### 5.4 플러그인 상세(구성과 흐름)

- 구역 둘: "무엇으로 되어 있나"와 "어떻게 움직이나".
- 위: 왼쪽 = 가져다 쓰는 것(층별 묶음, 주는 플러그인, 없음은 빈 점·점선), 가운데 = 플러그인 판(카드) 안의 블록(이름 + 한 줄), 오른쪽 = 끼어드는 훅과 내놓는 것.
- 아래: 단계 흐름. 단계마다 진행 한도, 들어오는 조건, 펼침(렌즈 셋). Helm은 고리(끝나면 쉼으로), 사람 확인 자리(결정 8)를 마름모로.
- 단계를 고르면 그 단계의 블록과 선만 진하고 나머지는 흐립니다. 내부 선 이름표도 고른 단계 것만 보입니다.
- 읽기 전용입니다(결정 2). 머리 동작은 "구성기에서 열기" 하나입니다.
- 그림은 고정 폭 900이고 좁으면 가로로 스크롤합니다(세계 맞춤 없음).
- 두 번째 예는 사용자 L1 비용 라우터입니다. [제안] L1.models 가상 모델 등록은 2차라 registerProvider로 그렸습니다.

## 6. 제안 원칙(DP 후보)

1. **V3-01 모든 층은 같은 모양으로 바꿀 수 있다.** 층을 고르면 내장 · 내 것 · 더하기를 같은 순서와 모양으로 둡니다. 더할 수 없는 층(F)은 표에 두지 않습니다.
2. **V3-02 관계는 목록으로.** 포커스 관계는 선 대신 표의 글자 낮추기와 관계 목록으로 보입니다.
3. **V3-04 보기와 바꾸기는 다른 자리.** 보기 = 왼쪽 위 칸, 바꾸기 = 표 위 카드 + 대상과 시점을 말하는 버튼("이 대화에 적용").
4. **V3-06 상세는 바깥 → 안 → 바깥.** 플러그인 상세는 가져다 쓰는 것(왼쪽) · 판 안 블록(가운데) · 끼어드는 곳과 내놓는 것(오른쪽), 그 아래 흐름. 고른 흐름 단계만 진하게.

V3-03(층 색), V3-05(그라디언트), V3-07(그림 위 HTML 글자)은 개편으로 뺐습니다.

## 7. 빈틈과 확인할 것

- **관계 데이터 출처.** 관계 렌즈는 매니페스트 `requires`·`optional`·`provides`, X 훅 등록(X-15), F 접두 선언, 그리고 "누가 이 기능을 지금 주나"(L2 레지스트리)를 합쳐야 합니다. 이 넷을 한 번에 주는 wire 조회가 없습니다(`ext.relations(id)` 같은 읽기 하나 [제안]). L1→L1 서비스 사용(Cordis `inject`)은 매니페스트에 없어 X 쪽 기록이 필요합니다.
- **F "플러그인".** F에는 사용자 플러그인이 없습니다. 시안은 "플러그인이 선언한 이름"만 보입니다. 사용자가 이것도 "더하기"로 기대하는지 확인이 필요합니다.
- **X 외부 훅의 층.** 외부 명령 훅을 X 행에 두었습니다. 문서상 외부 훅은 X가 실행하는 확장이므로 맞지만, 사용자는 "훅 = L3 그룹이 거는 것"과 헷갈릴 수 있습니다.
- **셸 문구.** 상태 줄 "이 컴퓨터(앱 안)", "drive helm"은 셸이 그립니다(§1.4).
- **caustic.** 층 표는 `_shell/line-grid`의 `LineGrid`(`density="compact"`로 칸 좌우 여백 12, 머리 칸 고르기 `onSelectRow`·`onSelectColumn`, 칸 안 이름 누르기 `onItemSelect`, 빠질 항목 `struck`)입니다. 이 목업의 옛 caustic 기반에는 선 격자가 없어 목업 안에 이식했습니다. 상세 그림은 이 폴더에서 토큰으로 그렸습니다. 정식 선 격자가 caustic에 생기면 그쪽으로 옮깁니다.
- **페이지 제목 크기.** 크래프트 머리(`WorkbenchHead`)는 공용 셸의 한 줄 머리(13px 제목)라 개편본의 큰 제목(title-1)과 다릅니다. 셸을 고치지 않았습니다.
