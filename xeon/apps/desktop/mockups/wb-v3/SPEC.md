# 크래프트 캔버스 v3 (wb-v3)

v2 A(층 건물·고리 그림)와 v2 B(플러그인 하위 캔버스) 가운데 사용자가 좋다고 한 것을 합치고, 싫다고 한 것을 고친 시안입니다. 근거는 `_notes/pages-brief.md` "Canvas v3 round", 캔버스 결정 9개, `m4-decisions.md`, 용어 점검(`_notes/terms-and-coverage.md` 1부)입니다. 이 문서는 desktop-ux spec에 합칠 제안입니다.

- 실행: `MOCKUP=wb-v3 bun run mockup`, `?state=<id>`, `?theme=dark`
- 일러스트: `mockups/_art`(m4/art 1d154234, 이 브랜치 24779e10)를 그대로 씁니다. 자리 표시 그림은 남기지 않았습니다.

| v2에서 받은 의견 | v3에서 한 일 |
| --- | --- |
| B의 플러그인 상세(구성과 흐름)가 좋음 | 가장 힘준 화면으로 키움. 플러그인 경계 판, 관련 선만 진하게, 단계 고르면 블록이 밝아짐(§5.4) |
| A의 X 고리 그림이 직관적 | 손그림 고리를 일러스트 `hero-lifecycle`로 바꾸고 단계 핀·훅 수·층 점을 그 위에 겹침(§5.1) |
| 플러그인이 다른 층과 어떻게 얽히는지 안 보임 | 포커스 + 관계 렌즈. 층마다 관계 줄, 줄마다 캔버스 대상으로 선 하나(§3) |
| L0, L1, X도 바꿀 수 있다는 게 안 보임 | 층 여섯 모두 내장 · 내 것 · "더하기" 자리를 같은 모양으로. L1 비용 라우터, L0 build-box, X 외부 훅 둘(§5.2) |
| 용어가 어색함 | 용어 표(§1), 화면은 추천안으로 |
| 맥락·프로필이 어려움 | "보기 기준"과 "프로필"으로 이름을 바꾸고, 보기 ≠ 바꾸기를 모양으로 나눔. 첫 설명 덮개(§4) |

## 1. 용어

원칙은 용어 점검 1.5절을 따릅니다. 대화 영역은 일상어만 쓰고, 크래프트는 한국어 라벨 + 회색 mono id를 씁니다. 기계 이름(`on`·`post`·`drive`·`scope`, `ext.*`, 훅 이름)은 그대로 mono로 둡니다. 비유어(소켓, 건물, 역)는 화면 라벨로 쓰지 않습니다.

## 2. 시각 언어

- **층 색(제안 V3-03, 캔버스 안에서만).** caustic identity 다섯(iris, mint, coral, slate, amber)을 L3·L2·L1·L0·X에 하나씩, F는 무채색입니다. 쓰는 자리는 셋뿐입니다: 띠 바닥판(5–7%), 아이콘 면 tint(14–22%), 선·점 ink. 블록 글자는 늘 neutral입니다. 모두 `color-mix(in oklab)`로 만들고 hex가 없습니다.
- **내장과 내 것.** 내장 타일은 종이색 면 + 아주 옅은 테두리입니다. 내 것은 층 색 고리 + 왼쪽 위 옅은 sheen + "내 것" 표지(사람 글리프)입니다. 일러스트도 같은 규칙입니다(그라디언트 = 내가 꽂은 것).
- **더하기 자리.** 층마다 맨 끝에 점선 윤곽 + "+" + "<명사> 더하기". 점선은 "아직 없는 것"에만 씁니다(V-06). F에는 더하기 대신 "직접 더하지 않아요"와 플러그인이 선언한 이름 칩(점선)을 둡니다.
- **선.** 기본은 선을 그리지 않습니다. 포커스, 상세의 고른 단계처럼 고른 것에 걸린 선만 진하게(1.4–1.6px, 층 ink), 나머지는 16% 이하로 둡니다. 선은 바탕색 3.5px 밑선 위에 그려 타일 가장자리와 섞이지 않게 합니다. 점선은 "없으면 건너뜀"(선택 의존)입니다.
- **깊이.** 테두리 대신 면과 그림자(`--lift`)로 올립니다. 고른 것은 accent 2px 고리, 맥박(`v3-breathe`)은 고른 단계 하나에만 씁니다. 움직임은 `prefers-reduced-motion`이면 끕니다.
- **일러스트.** 개요의 턴 흐름 그림, 개요 "층 여섯" 카드와 L1 더하기 시트의 층 쌓기 그림, 보기 기준 설명의 개념 그림 넷(spot-plugin·context·trial·profile)과 보기/바꾸기 두 칸에 씁니다. 글자는 그림 밖 HTML로 `anchors` 좌표에 겹칩니다.
- **글자 크기.** 캔버스는 세계 맞춤(Fit)으로 줄이되 최소 0.66배입니다. 그보다 좁으면 줄이지 않고 스크롤합니다(700px은 목록으로 바꿈).

## 3. 포커스와 관계 렌즈

### 3.1 들어가는 길

- 층 보기에서 타일을 누름, 개요 단계 카드의 훅 행을 누름, 표 보기의 행 이름을 누름.
- 포커스는 캔버스 위 머리 띠(포커스 띠)로 알립니다: 아이콘 · 이름 · id · "관계 17 · 층 6개에 걸쳐요" · 선 읽는 법 · "구성과 흐름 보기" · 닫기.

### 3.2 무엇을 보여 주나

층마다 관계 줄을 왼쪽 열(평소엔 층 설명 자리)에 둡니다. 줄은 "사람 말 + mono id + 층 색 점"이고, 줄 끝 점에서 선 하나가 그 층 띠의 대상으로 갑니다.

| 층 | 관계 | Helm 예 |
| --- | --- | --- |
| L3 | 나를 쓰는 그룹(←) | 학습이 발견 기록을 읽어요 `grp.helm.*` |
| L2 | 가져다 쓰는 기능(→), 대상은 그 기능을 지금 주는 플러그인 | 웹 검색 `web.search` → Exa 검색(내 것) |
| L1 | 쓰는 핵심 서비스(→) | 렌즈를 보조 에이전트로 `loop.spawn` |
| L0 | 쓰는 시스템 기반(→) | 상태·발견 저장 `ScopedStore` |
| X | 끼어드는 훅(⤳), 대상은 턴 흐름의 단계 핀 | 도구 · 쓰기 막기 `call.before +1` |
| F | 지키는 규약·선언한 이름(◇) | 그룹 기록 두 종류 `GroupRecord` |

사용자 L1 플러그인(비용 라우터) 포커스는 "모델 서비스를 씀 → L1 모델", "모델 요청 훅에 끼어듦", "Helm 렌즈가 route/auto로 불려요(←)", "기록 종류·설정 키 선언(◇)"을 보여 줍니다. 같은 층 협력은 import가 아니라 Cordis 서비스라서 L1 → L1 선도 그립니다. 그 밖의 플러그인은 훅 표에서 X·F 관계만 끌어냅니다(실제 앱은 매니페스트 `requires`·`optional`·`provides`와 X-15 훅 등록에서 만듭니다).

### 3.3 그리는 규칙

1. 관계 없는 타일은 32%로 흐리고, 관계 있는 타일은 층 ink 고리, 고른 타일은 accent 고리입니다. 관계 없는 층 바닥판도 흐립니다.
2. 포커스면 관계가 있는 띠의 높이를 늘리고 타일을 띠 아래쪽에 붙입니다. 위 여백이 선의 차선이 됩니다.
3. 띠 안 관계 줄은 대상이 오른쪽인 것부터 위에 둡니다. 위 줄 → 위 차선 → 오른쪽 대상이라서 선끼리 엇갈리지 않습니다.
4. 선은 "줄 → 짧은 S곡선 → 수평 차선 → 둥근 모서리 → 대상 위 가장자리"의 한 모양뿐입니다. 층을 건너는 선은 그리지 않습니다(층마다 자기 줄이 있음).
5. 선택 의존(없으면 건너뜀)은 점선, 지금 주는 플러그인이 없는 기능은 점선 줄 + 대상 없음입니다.
6. 상세로 가는 길은 포커스 띠의 "구성과 흐름 보기" 하나입니다.

## 4. 보기 기준과 프로필

### 4.1 모델

| | 보기 기준(옛 맥락) | 프로필(옛 프로필) |
| --- | --- | --- |
| 한 줄 | 지금 어느 런타임을 보고 있나 | 저장해 둔 켜기·끄기 묶음 |
| 값 | 설치 전체 · 대화(실시간) · 테스트 대화 · 프로필(설계도로 보기) | 이름 있는 스위치 묶음 + 설정 덮어쓰기 |
| 바뀌는 것 | 크래프트 모든 화면이 보여 주는 것만(결정 3) | 고른 대화의 켜짐·꺼짐(적용할 때만) |
| 모양 | 눈 아이콘 · 회색 글 · 왼쪽 위 칸 | 슬라이더 아이콘 · accent 면 · "이 대화에 적용" 버튼 |
| 저장 | 기기별 마지막 값, 대화 영역을 따라감(결정 11) | 런타임 설정(CLI·서비스와 공유, 결정 5) |

### 4.2 보기와 바꾸기를 가르는 규칙

- 보기 기준을 바꾸는 동작은 아무것도 바꾸지 않습니다. 칸 아래 한 줄이 늘 그렇게 말합니다("켜짐·꺼짐은 대화마다 달라요", "실시간 · 턴 7", "실행 안 함 · 스위치만 보여요").
- 대화를 보는 중에 칸에서 프로필을 고르면, 보기 기준은 대화 그대로 두고 **바꾸기 미리보기**를 엽니다. 머리 아래에 두 줄이 생깁니다: 회색 "보는 중 · 대화 캐시 무효화 조사 · 아직 그대로예요"와 accent 띠 "프로필 '탐구 중심'을 이 대화에 적용하면 + 켜짐 3 − 꺼짐 1 ~ 설정 1 · 주도 그대로 · 이번 단계가 끝나면 적용 [나란히 비교] [닫기] [이 대화에 적용]".
- 캔버스는 대화 테두리(accent 1.5px) 안에 지금 상태를 그리고, 바뀔 타일에만 +/−/~ 표지와 점선 윤곽을 겹칩니다.
- "나란히 비교"는 차이 화면입니다. 왼쪽 "지금(보기)", 가운데 바뀌는 것, 오른쪽 "적용하면(바꾸기)". 바뀌는 행만 보여 주고 같은 것은 수로 줄입니다. L0은 "어댑터는 시작할 때 정해져 프로필 밖이에요"라고 말합니다.
- 바꾸는 동작의 문구는 늘 "이 대화에 · 이번 단계가 끝나면"을 포함합니다.

### 4.3 처음 설명

보기 기준 칸 옆 `?`를 누르거나 처음 크래프트를 열면 덮개가 뜹니다(꼬리가 칸을 가리킴). 개념 그림 넷(설치 전체 · 대화 · 테스트 대화 · 프로필)과 아래 두 칸 "보기"(바꿔도 런타임은 그대로) · "바꾸기"(켜기·끄기와 프로필 적용만 런타임을 바꿈)입니다. 버튼은 "대화로 보기"와 "알겠어요"입니다.

## 5. 화면과 상태

내비 "구조"(옛 개요·런타임 지도) 하나에 보기 셋 [그림 | 층 | 표]를 두고, 플러그인 상세와 차이 화면이 그 아래에 있습니다. 왼쪽 패널, 오른쪽 떠 있는 막대와 well(받은 요청·기록·대화)은 §13 셸 그대로입니다.

### 5.1 그림(개요)

- 제목 두 줄: "한 턴은 훅 46곳을 차례로 지나요" · "플러그인은 이 훅에 끼어들어 턴을 바꿔요. 켜고 끈 것은 이번 단계가 끝나면 적용돼요."
- 일러스트 `hero-lifecycle` 위에 단계 핀 일곱. 핀 = 훅 수(원) · 이름 · mono 종류 · 훅을 건 층 점. 그림에 없는 안전 검사·수명 핀은 고리 위 빈 자리에 둡니다. 고른 단계가 도구면 `hero-lifecycle-active`로 바꿉니다.
- 오른쪽: 고른 단계 카드(훅별 fold 글리프, 실행 순서, 층, 내 것 표지, 실패 점) + "층 여섯 · 모두 바꿀 수 있어요" 카드(층 쌓기 그림, 층마다 내장 수 · 내 것 수 · 더하기 버튼).

### 5.2 층

- 위 L3부터 아래 F까지 띠 여섯. 왼쪽 열은 층 이름 · 해 주는 일 · "내장 n · 내 것 m · 붙는 방식"입니다.
- 내 것 예: L3 렌즈 리뷰(Helm 복제), L2 Exa 검색, acme 노트(프로젝트), L1 **비용 라우터**, L0 **build-box 원격**(exec 대신), X **시크릿 검사**·**끝나면 알림**(외부 훅).
- X 띠는 내장이 플러그인이 아니라 연산 넷(훅 `on`, 입력 넣기 `post`, 주도 `drive`, 켜고 끄기 `scope`)이라는 것을 한 묶음 카드로 보이고, 아래에 턴 흐름 길(단계 일곱, 단계마다 훅 막대 = 층 색)을 둡니다. 사용자가 X에 더하는 것은 "훅"(외부 명령 훅, 훅 하나에 참여)입니다.
- F 띠: 규약 다섯(대화·기록·기능·확장·연결·설정)과 플러그인이 접두로 선언한 이름 셋(`notes.search`, `x.cost-router.*`, `ext.cost-router.*`). "직접 더하지 않아요"로 정직하게 표시합니다. F에 사용자 "플러그인"은 없고, 플러그인이 F 규칙 안에서 이름을 선언해 늘린다는 뜻입니다(F.extensions §3.1 접두 규칙).
- 자동 배치(결정 4): 층마다 내장 → 내 것 → 더하기. 머리의 되돌리기 버튼이 "자동 배치로 되돌리기"입니다.

### 5.3 에이전트 핵심(L1)에 더하기 · 시작

L1 띠 더하기 자리를 누르면 오른쪽 시트가 열리고, 캔버스의 L1 띠만 밝게, 더하기 자리는 "여기에 놓여요"로 맥박칩니다. 시트: 층 쌓기 꽂기 그림, 단계 셋(가져오기 · 검사·신뢰 · 켜기), "이 층에서 할 수 있는 것"(provider 등록, 요청·도구 훅 훅, 도구 등록 / 주도는 그룹만 `drive_requires_group`), 가져올 곳 셋(만들기 도우미 = 플러그인을 만드는 플러그인, 결정 8 · 폴더 · 설치된 것 복제).

### 5.4 플러그인 상세(구성과 흐름)

- 위 "무엇으로 되어 있나": 왼쪽 바깥 = 가져다 쓰는 것(층별 묶음, 주는 플러그인, 없음은 점선), 가운데 = **플러그인 경계 판** 안의 블록(주도 블록은 검은 아이콘 면, 블록마다 이름 · 역할 mono · 한 줄), 오른쪽 바깥 = 끼어드는 훅과 내놓는 것. 판 아래에 "Helm 안 · 블록 7 · 작성자가 선언(`composition`)"(결정 7).
- 아래 "어떻게 움직이나": 단계 흐름. 단계마다 진행 한도, 들어오는 조건(◇), 움직이는 블록 아이콘, 펼침(렌즈 셋). Helm은 고리(끝나면 쉼으로), 사람 확인 자리(결정 8)를 마름모로.
- 단계를 고르면 그 단계의 블록과 선만 진하고 나머지는 흐립니다. 내부 선 이름표도 고른 단계 것만 보입니다. 주도 블록의 출력선은 판 위 차선으로 돌아 오른쪽 블록 열을 가로지르지 않습니다.
- 읽기 전용입니다(결정 2). "구성기에서 열기"만 있습니다.
- 두 번째 예는 사용자 L1 비용 라우터입니다. 같은 문법으로 "모델 서비스·역할 표 → 재기·규칙 → 모델 고르기 → 요청 고치기 → 비용 기록", 훅 `request.provider.before`(chain)·`request.model.after`(tap), 내놓는 것 provider `route/auto`를 보입니다. [제안] L1.models 가상 모델 등록은 2차라 registerProvider로 그렸습니다.

## 6. 제안 원칙(DP 후보)

1. **V3-01 모든 층은 같은 모양으로 바꿀 수 있다.** 층마다 내장 · 내 것 · 더하기 자리를 같은 순서와 모양으로 둡니다. 더할 수 없는 층(F)은 빈자리 대신 이유를 씁니다.
2. **V3-02 관계는 층마다 줄 하나, 선 하나.** 포커스 관계는 층별 목록 줄과 그 층 안의 짧은 선으로 그립니다. 층을 건너는 선과 모든 선을 한 번에 그리는 것은 쓰지 않습니다. 줄 순서는 대상 위치로 정해 선이 엇갈리지 않게 합니다.
3. **V3-03 층 색은 캔버스 안, 면·선·점에만.** 글자는 neutral, 상태는 tone 점으로 따로.
4. **V3-04 보기와 바꾸기는 다른 모양.** 보기 = 눈 + 회색 + 왼쪽 위 칸, 바꾸기 = 슬라이더 + accent 면 + 대상과 시점을 말하는 버튼("이 대화에 · 이번 단계가 끝나면").
5. **V3-05 그라디언트는 내가 더한 것.** 일러스트와 타일 모두, 기본 것은 종이색, 사용자 것만 색 sheen.
6. **V3-06 상세는 바깥 → 안 → 바깥.** 플러그인 상세는 가져다 쓰는 것(왼쪽) · 경계 판 안 블록(가운데) · 끼어드는 곳과 내놓는 것(오른쪽), 그 아래 흐름. 고른 흐름 단계만 진하게.
7. **V3-07 그림의 글자는 HTML.** 일러스트에는 글자를 넣지 않고 기준점에 HTML 라벨을 겹쳐 번역·접근성·어두움을 지킵니다.

## 7. 빈틈과 확인할 것

- **관계 데이터 출처.** 관계 렌즈는 매니페스트 `requires`·`optional`·`provides`, X 훅 등록(X-15), F 접두 선언, 그리고 "누가 이 기능을 지금 주나"(L2 레지스트리)를 합쳐야 합니다. 이 넷을 한 번에 주는 wire 조회가 없습니다(`ext.relations(id)` 같은 읽기 하나 [제안]). L1→L1 서비스 사용(Cordis `inject`)은 매니페스트에 없어 X 쪽 기록이 필요합니다.
- **F "플러그인".** F에는 사용자 플러그인이 없습니다. 시안은 "플러그인이 선언한 이름"만 보입니다. 사용자가 이것도 "더하기"로 기대하는지 확인이 필요합니다.
- **X 외부 훅의 층.** 외부 명령 훅을 X 띠에 두었습니다. 문서상 외부 훅은 X가 실행하는 확장이므로 맞지만, 사용자는 "훅 = L3 그룹이 거는 것"과 헷갈릴 수 있습니다. 툴팁으로 "외부 명령 · 늘 맨 뒤"를 말합니다.
- **안전 검사·수명 단계 그림.** 일러스트는 다섯 단계라 두 핀은 그림 밖 자리에 얹었습니다. 일러스트레이터에게 일곱 단계판을 요청할지 정해야 합니다.
- **셸 문구.** 상태 줄 "앱 안 엔진", "drive helm"은 셸이 그립니다(§1.4).
- **caustic.** 층 띠 자동 배치, 세계 맞춤, 렌즈 줄 → 차선 선은 이 폴더 `parts/kit.tsx`·`screens/layer-world.tsx`에 토큰으로 그렸습니다. 재사용이 확실해지면 `CanvasViewport`(맞춤·최소 배율)와 `LaneRouter`(엇갈리지 않는 차선 선)를 caustic에 올리기를 제안합니다. 이번에 caustic은 고치지 않았습니다.
