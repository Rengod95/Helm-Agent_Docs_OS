# d02 셸 수명 (N-51~N-56, N-58, S-04, 계획에 없음 1·5·10)

## 레이아웃 결정
- 창 위 띠를 만들지 않습니다(DP-05). 엔진·연결·안전 모드·업데이트·진행 중은 모두 상태 표시줄 칸과 그 Popover로만 드러내고, 무대에는 입력창 바로 위 띠 하나(재기동 중) 또는 카드 하나(안전 모드 제안)만 둡니다.
- 엔진 실패는 §6.3 그림대로 엔진 칸 옆에 띠 위 버튼 둘("엔진 다시 시작", "진단 복사")을 바로 둡니다. 실패 동안 목록은 흐리게, 입력은 잠그되 쓰던 글은 남깁니다.
- 안전 모드 제안 카드는 입력창 자리를 대신합니다(보낼 수 없으니). 원인은 `safeModeCause`와 확장 이름 + 회색 id(결정 13), stderr 마지막 20줄은 펼쳐 봅니다. 확정 버튼은 "안전 모드로 시작" 하나, 다시 시도는 outline.
- 안전 모드 문구는 한 상수(`parts/life.tsx SAFE_OFF`: 그룹, 사용자·프로젝트 확장, X 훅)를 모든 곳(띠, 카드, 칩, 런타임 줄, d03 P-15)이 씁니다(결정 12, N-56).
- 대화 영역 안전 모드 표시(계획에 없음 5): 연결 칸 뒤 칩 "안전 모드"(warning 점). Popover에 빠진 그룹·확장·X 훅과 원인, "엔진 화면 열기"(크래프트 P-15), "안전 모드 끄고 다시 시작". 대화 머리 런타임 줄도 "안전 모드 · … 꺼짐 · 주도 없음"이라 Helm이 왜 없는지 바로 보입니다.
- 업데이트(계획에 없음 1): 상태 표시줄 점 하나 + Popover(버전, 바뀐 점 3줄, 진행 막대). 다시 시작 전에 진행 중 턴이 있으면 확인(기본 초점 "나중에", "턴이 끝나면"은 자동으로 이어짐). 서명 불일치는 설치를 멈추고 "그래도 설치"를 두지 않습니다. P-15 줄은 d03 `?page=p15&state=D-update`.
- 진행 중(N-58, 계획에 없음 10): 모델 칸 앞 "진행 중 n". Popover는 넓은 크기(lg)로 대화·테스트 대화·예약·제작 대화를 묶음 제목(tertiary)과 행(muted 아이콘)으로, 실패 행만 danger 아이콘 면(DP-29). 엔진이 없으면 칸을 숨깁니다. compact 폭에서는 빠집니다.
- 토스트(S-04, 결정 14): `_shell/parts/shell-toaster.tsx` `ShellToaster`가 well이 열리면 well 왼쪽 끝으로, 닫히면 막대 옆으로 옮깁니다. compact 폭은 가운데 아래(상태 표시줄 위).
- OS 알림(N-53): 배너는 앱 밖이라 "OS 알림 미리보기" 영역으로 화면 오른쪽 위에 따로 그립니다(caustic 토큰만, OS 모양 흉내 없음). 문구: 제목 "무엇 · 대화", 본문 한 줄, 명령 전문·시크릿 없음. 누르면 원인 화면(승인 → 그 대화의 카드에 강조 테두리). 창이 앞에 있어도 앱 안 토스트도 함께 뜹니다(§6.4 기본값). 권한 거부는 토스트 한 번 + 설정 "실행과 서비스" 탭 알림 묶음 위 Alert.
- 메뉴 막대 아이콘(N-51)과 macOS 앱 메뉴(N-52)는 창 위 24px "OS 화면" 띠로 그렸습니다. 아이콘 메뉴: Fresnel 열기, 승인 기다림 n, 진행 중, 새 대화, 알림 1시간 끄기, 업데이트 확인…, 종료. 창을 닫은 뒤(`closeBehavior=tray`) 상태도 있습니다.
- 웹: 엔진 칸 대신 "서비스 응답 없음 n/3" + "다시 연결"만(엔진 다시 시작 없음, `web-failed`).

## caustic 부품
`Alert`, `Button`, `Card`, `Dialog`(alert), `ListDescription`, `Menu`(inline)·`MenuItem`·`MenuSeparator`, `Popover`(상태 칸), `Progress`, `Select`, `Switch`, `Toaster`·`toast`, 공용 `_settings` 틀(`SettingsFrame`, `SettingRow`, `SettingSection`).

## 직접 만든 것과 빈틈
- 상태 표시줄 칸에 선택 항목을 더했습니다(`_shell/parts/status-bar.tsx`): `body`(Popover 본문), `secondary`(둘째 동작), `inline`(띠 위 버튼), `defaultOpen`, `wide`. `defaultStatusCells`에는 `target`, `engine`, `startExtra`, `live`, `endExtra`. 주지 않으면 예전과 같습니다.
- 창 전체 "다시 시작하는 중" 화면(`Relaunch`)은 caustic에 전체 화면 로딩 부품이 없어 토큰으로 짰습니다.
- OS 배너·메뉴 막대는 목업 전용 그림입니다(실제는 Tauri tray·menu·notification 플러그인).

## 웹·좁은 폭
- 700px: 상태 표시줄이 대상·연결·승인만 남기므로 엔진 실패 칸은 연결 칸 앞에 남깁니다(`engine-failed-700`). 진행 중 칸은 빠집니다. 토스트는 가운데 아래.
- 웹: 엔진 다시 시작·안전 모드로 시작이 없고(서비스 쪽 일) "다시 연결"만. 업데이트는 웹에 없습니다(서비스 버전만 P-15에 표시). OS 알림은 브라우저 알림 권한이고, 탭을 닫으면 오지 않습니다. 메뉴 막대·앱 메뉴는 데스크톱만입니다.
