# c02-ext-detail 메모

P-17 확장 상세의 탭 넷(버전, 설정, 화면, 기록)과 X 훅 상세, O-11 되돌리기입니다. 개요·연결 지점·임대·측정 탭은 wb-opus 시안을 따르고 이 폴더에서는 다시 그리지 않았습니다(개요 탭에 링크).

## 레이아웃 결정

- 머리: 표시 이름 + 회색 mono id(결정 13), 층 mono, 종류 · 등급 · 버전, 상태 점. 동작은 "끄기" + 더보기 메뉴(시험 시작, 다시 읽기, 폴더 열기/경로 복사, 확장 정보 파일 복사).
- 버전 탭 두 단계(§6.24.1)는 한 탭에서 엔진 능력에 따라 모양만 바뀝니다. 전체 단계는 이력 표, 대체 단계는 목록 두 줄 + "이 엔진은 설치 이력을 남기지 않아요" 한 줄 + 단추 하나.
- O-11은 `Dialog kind="alert"` 안에서 진행과 실패 원복까지 보입니다. 진행 중에는 닫기·취소가 없고 바닥에 "n/4"만. 형식 변환이 없으면 danger 단추 "저장 데이터를 비우고 되돌리기"와 보조 "코드만 되돌리기"(2026-11-01 결정) 둘.
- 설정 탭 값 출처는 SettingRow(p09와 같은 부품) 아래 한 줄 "값 출처 · <범위> 범위가 이김 · 경로" + 가려진 범위 값 펼침. 범위 배지는 행마다 하나(DP-36). 보기 기준이 프로필·시험이면 탭 맨 위에 "저장 위치" 띠 하나로 쓰기 대상을 밝힙니다.
- settings slot은 스키마 필드 맨 아래, 연한 머리 "Helm이 그린 부분 · 읽기 전용 · id" 다음 플러그인 트리(선·상자 없음, DP-42).
- 화면 탭: 표 위 Alert 하나(DP-28), 표 아래 진단 목록(코드 mono + 문장).
- 기록 탭: 진단 위치는 행 셋째 줄 mono + "파일 열기"(OS 기본 편집기). 웹·원격은 "경로 복사".

## caustic 부품

`Tabs`(soft xs), `Select`(좁은 폭 탭), `Dialog kind="alert"`, `ListDescription`, `Alert`, `Badge`, `Button`, `Menu`, `NumberField`, `Toaster`. 설정 행은 `../_settings/row.tsx`(SettingRow), 가려진 범위는 `../_settings/parts.tsx`(ShadowedScopes)를 고치지 않고 가져다 씁니다.

## 빈틈

- 진행 단계 목록: Stepper는 가로·체크리스트 모양이라 대화 상자 안 네 줄 진행(✓·스피너·✕)에 무겁습니다. 토큰으로 짰습니다.
- "범위 배지"에 프로필·시험 값이 `_settings/row.tsx`의 Scope에 없어 `flag`로 Badge를 줬습니다. 공용 Scope에 `profile`·`trial`을 더하기를 제안합니다.

- 웹·원격: "폴더 열기"·"파일 열기" 대신 "경로 복사".
