# c02-ext-detail 시나리오

P-17 확장 상세의 버전·설정·화면·기록 탭과 O-11 되돌리기, X 훅 상세입니다. 상태와 시나리오는 `flow.ts`의 상태 기계 하나입니다(`?state=`, `?scenario=<id>&step=<n>&hold=1`, `?dev=1`).

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `revert` | ① 설치 이력 0.0.9 행 "되돌리기" → ② "되돌리기" → (기다림) | ① O-11: 지금 0.1.0·저장 형식 3, 되돌릴 0.0.9·저장 형식 2, 형식 변환 "3 → 2 있음 migrations/3-to-2.ts", 기본 초점 "취소" ② 대화 상자 안 진행 네 줄(끄기 → 0.0.9 파일로 바꾸기 → 저장 형식 3 → 2로 형식 변환 → 이번 단계가 끝나면 켜기) → 닫히고 이력의 "지금"이 0.0.9, 토스트 | spec §6.24.1, §6.31 O-11, 결정 6 |
| `revert-fail` | 위와 같음 | 형식 변환 줄이 danger 면 ✕, 제목 "원래대로 돌리는 중", "0.1.0 파일로 돌리기" → 닫히고 탭 위 Alert "되돌리지 못했어요… 0.1.0 파일로 돌려 놨어요. 저장 데이터는 그대로예요" + 진단 위치 | §6.24.1(실패하면 이전 파일로) |
| `revert-no-migration` | ① 0.0.6 행 "되돌리기" → ② "저장 데이터를 비우고 되돌리기" | ① 형식 변환 "3 → 1로 내리는 형식 변환이 없어요" + warning Alert(비울 데이터 수), 단추는 "코드만 되돌리기"(보조)와 danger "저장 데이터를 비우고 되돌리기" ② 진행의 셋째 줄이 "저장 데이터 비우기" → 끝, 탭 위 "저장 데이터를 비웠어요" | 결정 6, 2026-11-01 결정(형식이 바뀌면 코드만 되돌리기 대안) |
| `views-reenable` | 화면 탭 → "화면 다시 켜기" | 꺼진 `helm/suggested` 행이 켜짐 0/5, Alert와 탭 숫자가 줄어듦, 토스트 | N-33, ADR-0021 §3.6 view_disabled |

스크린숏 순간: `sc-revert-1`(확인), `sc-revert-3`(진행), `sc-revert-6`(끝), `sc-revertfail-5`(원복 중), `sc-revertfail-6`(실패 결과), `sc-nomig-1`, `sc-nomig-6`, `sc-views-2`.

## ?state= 목록

| id | 모습 |
|---|---|
| `versions`(기본) | 전체 단계: Helm 설치 이력(버전, 설치, 출처, 매니페스트 해시, 저장 형식, 되돌리기) |
| `versions-builtin` | 대체 단계 · 기본 플러그인(학습): 설치본 0.4.1, 앱에 든 버전 0.4.0, "앱에 든 버전으로 되돌리기" |
| `versions-user` | 대체 단계 · 사용자 확장(Acme 노트): 되돌리기 없음, "폴더 열기" |
| `versions-web` | 웹·원격: "폴더 열기" 대신 "경로 복사" |
| `revert-confirm` · `revert-nomig` · `revert-progress` · `revert-done` · `revert-failed` | O-11 확인, 형식 변환 없음, 진행, 끝, 실패 원복 |
| `settings` | 설정 탭: 행마다 이긴 범위 배지, "값 출처 · 프로젝트 범위가 이김 · 경로", 가려진 범위 값, 아래에 Helm이 그린 읽기 전용 부분(settings slot) |
| `settings-profile` | 보기 기준 프로필: 머리 띠 "저장 위치 · 프로필 탐구 중심", maxLenses는 프로필이 이김 |
| `settings-trial` | 보기 기준 시험: "저장 위치 · 시험 대화 렌즈 5개로 넓히기 · session", maxLenses 5는 시험이 이김 |
| `views` | 화면 탭: 자리, id, 화면 방식(기본 부품·자체 코드), 상태, 실패 n/5, "화면 다시 켜기", 진단(`render_threw`, `view_mode_not_allowed`) |
| `log` · `log-web` | 기록 탭: 진단 위치 `file:line` + "파일 열기"(웹은 "경로 복사") |
| `hook` · `hook-safe` | X 훅(감사 기록 훅) 상세: 훅 이벤트, 명령, 범위, 시간, 실패 / 안전 모드라 싣지 않음 |
| `narrow` | 390px: 탭이 Select 하나, 이력이 두 줄 목록 |
