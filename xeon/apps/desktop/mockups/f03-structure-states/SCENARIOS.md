# f03 구조 화면 상태 · 시나리오

`?scenario=<id>`(`&dev=1`이면 막대), `&step=<n>&hold=1`은 그 단계에 멈춘 모습. 스크린숏 `sc-<id>-<n>.png`.

| 시나리오 | 누르는 순서 | 화면에서 바뀌는 것 | 근거 |
|---|---|---|---|
| `reload-offline` | (기다림) → (기다림) → "다시 연결" → (기다림) | 0 칸마다 글자 자리인 표 → 1 표가 채워지고 기능 층을 고른 상태 → 2 연결 칸 "끊김", "14:03 기준", Alert, 칸 글자 흐림, "기능 더하기" 잠금 → 3 다시 글자 자리 → 4 평상 화면과 토스트 "다시 연결됐어요" | P-16 S10, §6.21 |
| `safe-restart` (실패) | "안전 모드로 다시 시작" → (기다림) → "안전 모드 끄고 다시 시작" → (기다림) | 0 리뷰 자동 꺼짐 Alert → 1 글자 자리 + "안전 모드로 시작하는 중이에요…" → 2 그룹·확장 런타임 행이 빗금과 "빠짐", 사용자·프로젝트 확장이 칸에서 사라짐, 상태 칩 "안전 모드", "진행 없음", 표 아래 "이번 실행에서 빠진 것" → 3 글자 자리 → 4 처음 화면 | SC-22, §6.22, 결정 12, W-35 |

## `?state=` 목록

`safe-mode`(기본), `loading`, `offline`, `empty`, `narrow`(폭 700으로 볼 것), `web`.
모든 상태에서 칸·층·단계를 눌러 표 아래 구역을 바꿀 수 있습니다(`loading` 제외). 플러그인 이름을 누르면 그 플러그인 구역이 열립니다. 데스크톱은 "파일 열기"·"폴더 열기", `web`은 "경로 복사"입니다(시나리오의 평상 화면에서 견줄 수 있습니다).
