# a04-chat-tour 시나리오

대화 영역 둘러보기(N-14)를 눌러 봅니다. 세 곳을 차례로 짚습니다: 런타임 줄 → 런타임 탭 → "작업대에서 보기". 단계가 셋뿐이라 `&step=`을 쓰지 않고 순간마다 `?state=`를 둡니다. `?dev=1`이면 시나리오 막대가 보입니다.

## 시나리오

| id | 누르는 것 | 화면에서 바뀌는 것 | 순간(?state=) | 근거 |
|---|---|---|---|---|
| `tour` | 트랜스크립트 끝 런타임 행 "둘러보기" → "다음" ×2 → "다 봤어요"(또는 "그만 보기", "이전") | 1: 런타임 줄에 초점 고리와 말풍선 → 2: 런타임 탭이 열리고 탭 전체에 고리, 말풍선은 탭 왼쪽 → 3: "작업대에서 보기" 버튼에 고리 → 끝: 토스트 "둘러보기를 마쳤어요 · 도움말에서 다시 볼 수 있어요" | `entry`, `tour-1`, `tour-2`, `tour-3`, `done` | m4-plan T-CHAT2, spec §6.30 |
| `tour-closed` | `tour`와 같이 2단계까지 | 실패 갈래: 1.5초 뒤 런타임 탭이 닫힘(사용자가 Esc를 누른 것처럼) → 말풍선이 "런타임 탭이 닫혀 있어요 · 다시 열면 이어서 짚어 드려요"와 "런타임 탭 다시 열기" | `missing` | 실패 갈래 |

## ?state= 목록

| id | 모습 |
|---|---|
| `tour-1`(기본) | 1/3 런타임 줄 |
| `entry` | 시작점: 트랜스크립트 끝 흐린 런타임 행과 "둘러보기" |
| `tour-2` | 2/3 런타임 탭 |
| `tour-3` | 3/3 작업대에서 보기 |

| `missing` | 실패: 대상(런타임 탭)이 닫힘 |
| `narrow-1` | 390px 1/3: 말풍선이 아래 시트 |
| `narrow-2` | 390px 2/3: 런타임 탭이 시트, 말풍선은 그 아래 |
| `w700-3` | 700px 3/3 |
