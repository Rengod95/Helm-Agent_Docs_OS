# c03-ext-list 메모

P-13 확장 목록에 켜는 범위·대기(N-35)와 X 훅 행(N-36)을 더한 시안입니다. 가져오기·신뢰(O-10, N-37)는 묶음 B가 맡아 단추 자리만 둡니다.

## 레이아웃 결정

- 범위는 스위치를 켤 때만 묻습니다. 꺼진 행의 스위치를 누르면 그 스위치에 붙은 팝오버 하나(라디오 셋 + 저장 위치 한 줄 + 켜기). 보기 기준이 대화가 아니면 "이 대화만"을 빼고, 프로필·테스트이면 팝오버 없이 바로 프로필·그 테스트에 씁니다(머리 띠 하나가 뜻을 밝힘).
- 대기는 상태 열의 info 점 + "이번 단계가 끝나면 적용" 한 줄입니다(배지 대신 점 + 글, DP-29). 기다리는 동안 스위치는 켜짐 + 잠김.
- 기능 대기와 자동 꺼짐은 표 위 danger Alert 하나로 모읍니다(DP-28). 행에는 없는 기능 id를 mono로.
- 관리 잠금은 스위치 앞 작은 자물쇠 + 눌러 여는 이유 툴팁. 면제(core)는 "항상 켜짐"과 툴팁.
- X 훅은 층 묶음의 마지막 "X 확장 연결부 · X 훅"이고, 연산 열 자리에 훅 이벤트와 p50, 상태 열에 실패 수를 씁니다. 머리 끝 "hooks.list · 시각".
- 머리 둘째 줄: 보기 기준이 대화 하나면 "이 대화: 켜진 그룹 2 · 주도 Helm" 한 줄만(DP-23, 자세한 것은 런타임 탭).

## caustic 부품

`Switch`, `Popover`, `RadioGroup`, `Tooltip`, `Alert`, `Input`, `Select`, `Badge`, `Button`, `Toaster`.

## 빈틈

- 표: 층 묶음 머리가 있는 ghost 격자를 caustic Table로 그릴 수 없어 role=table 격자로 짰습니다(`[gap:C-21]`과 같은 이유).
- 상태 점 + 글(`DotText`, C-23).

## 웹·좁은 폭

- 720 아래: 이름 · 상태 · 켜기 세 열, 가져오기 단추 숨김. 웹은 차이 없음(범위 파일 경로가 원격 호스트 기준).
