# 크래프트 v4 (wb-v4)

확장 · 구성 · 엔진 세 화면을 한 화면으로 합친 시안입니다. 상태 전환기는 없고 눌러서 봅니다. 실행: `MOCKUP=wb-v4 bun run mockup`.

## 배치

- 위: 범위 막대(전역 → 프로필 → 프로젝트 → 대화). 고른 범위까지가 지금 보는 값이고, 쓰기는 늘 고른 범위로 갑니다. 오른쪽 칸이 어디에 저장하는지 말합니다.
- 위 둘째: 단위 막대(전체 루프 / 플러그인 그룹 / 플러그인), 이동 경로, 표 | 루프, 확장, 상세, 플러그인 만들기.
- 가운데: 캔버스. 표(층 × 단계 선 격자)와 루프(2D SVG)는 같은 데이터(`data.ts`)의 두 보기입니다.
- 오른쪽: 상세(흐름 / 프로필 / 코드). 탭 제목이 단위 이름을 말합니다(예: "Helm 흐름").
- 왼쪽 서랍: 확장 트리(그룹 › 플러그인, 거르기, 가져오기). 캔버스 위에 뜹니다.
- 아래 서랍: 엔진(주도, 실패, 지표). 실패 행을 누르면 그 플러그인과 훅이 고른 것이 됩니다.
- 빌더: "플러그인 만들기"와 빈 칸의 "더하기"가 엽니다. 대화 | 도구(템플릿, 스킬, 확장 정보 파일, 실행 테스트). 범위·단위·자리를 위에 보입니다.

## 눌러 보기

Helm 누르기 → 칸이 밝아짐 → 루프 → 훅 누르기(상세 열림) → 범위를 대화로 → 덮어쓴 값 표식(점) → 플러그인 만들기 → 템플릿이 골라진 빌더.

## 아직 모형인 것

설정 값 고치기(알림만), 가져오기(알림만), 에이전트 대화(정해진 답), 실행 테스트(가짜 결과), 코드 탭 파일 내용(데이터에서 만든 매니페스트·훅 줄만), 프로필 적용(알림만), 테스트·성능 측정 내비(옆 시안으로 감).
